# Правила работы с примерами

Для всего репозитория действуют [общие правила кода](doc/CODE-RULES.md). Прочитайте их перед изменением приложений, их архитектуры или интеграции с `wenay-common2` и `wenay-react2`.

Рабочий контекст продолжения — [doc/internal/](doc/internal/README.md); перед возобновлением работы прочитайте [doc/internal/NEXT-CHAT.md](doc/internal/NEXT-CHAT.md).

Правила коммитов и ветки `main` — в разделе «Коммиты» тех же общих правил.

Более узкий `AGENTS.md` внутри каталога может уточнять эти правила для своей области. Явные указания пользователя имеют приоритет.
