# wenay-examples

Каталог небольших законченных SaaS на **wenay-common2** и **wenay-react2**. Каждый пример — рабочий продукт с ролями, хранением, проверками и понятным путём масштабирования, пригодный как основа нового проекта.

Репозиторий решает две задачи сразу: даёт основу для быстрого старта и на реальных сценариях выясняет, каких возможностей не хватает библиотекам.

Текущие зависимости: **common2 2.21.1 / react2 3.5.1**.

## Быстрый старт

```text
cd apps/support
npm ci
npm test
npm start
```

Каждое приложение запускается самостоятельно и не требует соседних. Порт и каталог данных меняются переменными `SERVICE_PORT` и `SERVICE_DATA_DIR`.

## Своё приложение из готового

```text
node scripts/create-saas-example.mjs approvals ../my-approvals --name my-approvals
cd ../my-approvals && npm ci && npm run typecheck && npm test && npm run build
```

Копируются только исходники, точные npm-зависимости и правила. Прогоняйте все четыре команды сразу: scaffold переносит и проверки исходного примера. Что менять дальше — [рецепты для разработчика и ИИ](doc/SAAS-RECIPES.md).

## Проверка всего каталога

```text
npm run check:all
```

Последовательно прогоняет typecheck, тесты и сборку всех приложений, проверяет синхронность общего кода, правила плотности и ссылки. Отдельно: `test:all`, `status`, `style:check`, `sync:check`, `links:check`.
