# wenay-examples

Самостоятельные приложения на `wenay-common2` и `wenay-react2` в одном репозитории.

## План

1. `apps/pizzeria` — первый полноценный пример: клиент оформляет заказ, повар готовит, курьер доставляет, владелец управляет меню и ролями. Реальный backend, живые обновления и интерфейс на wenay-react2.
2. `apps/hosting` — развёртывание приложений, обновления и откат с визуальным управлением.
3. `apps/apartments` — бронирования и внешние эффекты.
4. `apps/catalog` — общая страница выбора готовых примеров.

Каждое приложение получает собственные frontend, backend, настройки, инструкцию запуска и развёртывания. Общая инфраструктура не должна мешать самостоятельному запуску примеров.

## Разработка

Библиотеки остаются отдельными репозиториями. Приложения используют публичные экспорты пакетов. Для совместной разработки допустимы локальные сборки; готовый пример проверяется также с явно указанными версиями пакетов.

Исходная серверная модель пиццерии находится в репозитории wenay-common2: `experiments/wenay-scaffold/examples/pizzeria`. Каталог `examples` там генерируется. Предметная логика и интерфейсы приложений остаются здесь; повторно используемые механизмы добавляются в соответствующую библиотеку по выявленной потребности.

## Состояние

Создан начальный репозиторий. Рабочие приложения будут добавлены следующими изменениями; команд запуска пока нет.
