# Витрина примеров

Запуск из корня репозитория: `node apps/catalog/server.mjs`, затем http://127.0.0.1:3800/. Порт задаётся `CATALOG_PORT`. Node без дополнительных зависимостей; сервер слушает только loopback и отдаёт явно разрешённые файлы. Не запускает другие приложения, не управляет Docker, не хранит данные.

Статическая витрина описывает сценарии, роли, команды самостоятельной копии и ограничения. Продукты открываются в отдельной вкладке; до этого их нужно запустить по своим README. Это обычный HTML-каталог, а сами приложения используют опубликованные common2/react2.

Для снимка настоящего интерфейса добавьте `doc/screenshots/{support,documents,metering,crm,booking,forms}.png` и `screenshot: true` к записи продукта в catalog.js. Иначе карточка показывает подписанную схему сценария — она не выдаётся за снимок. Метаданные обновляются вместе с SAAS-ACCEPTANCE.md. Будущие продукты видны только в фильтре «Все примеры».
