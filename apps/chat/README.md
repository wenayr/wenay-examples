# Рядом · общий чат

Web-чат [плана Q12](../../doc/AI-CHAT-PRODUCT-PLAN.md): история разговора на нескольких
клиентах, смена аккаунта и два фиксированных рабочих пространства C03.
Обычная отправка сохраняет сообщение;
тестовый помощник отвечает только после отдельного нажатия.

<!-- status:versions -->
Текущие зависимости: **common2 3.1.1 / react2 5.0.0**.
<!-- /status:versions -->

## Запуск

```text
npm ci
npm run typecheck
npm test
npm run build
npm start
```

Откройте `http://127.0.0.1:3819` в двух окнах. Войдите как Алиса и Боб
(`alice` / `alice-pass`, `bob` / `bob-pass`). «Общий разговор» виден обоим;
«Личный разговор» C01 остаётся в «Команде» и доступен только Алисе.
У Алисы также есть отдельное «Личное пространство» с новой историей; у Боба
оно отсутствует. Селектор пространства действует независимо в каждом окне.
«Сменить аккаунт» возвращает к входу; «Выйти» удаляет локальную сессию.
Отправьте сообщение и проверьте
другой клиент. Кнопка «Ответ тестового помощника» добавляет законченный
демонстрационный ответ без обращения к внешней модели.

Для разработки: `npm start`, затем `npm run dev`. Vite использует backend
из `SERVICE_UPSTREAM`, по умолчанию `http://127.0.0.1:3819`.
`SERVICE_PORT`, `SERVICE_HOST` и `SERVICE_DATA_DIR` меняют адрес и каталог данных.
По умолчанию сервер слушает loopback, данные записывает в `chat-data`.

## Как устроено

Сервис common2 определяет identity и текущую workspace membership, выдаёт
authority-ресурсы `chat` (team) и `chatPersonal` (personal).
Каждый conversation host хранит собственные разговоры, каналы, сообщения и receipts.
Team сохраняет прежний C01 журнал и личный разговор Алисы; новый Personal имеет
отдельный журнал. Старую личную историю автоматически в него не переносим.
Persistence port записывает библиотечные event и receipt вместе в журнал
с `fsync`; при перезапуске восстанавливает историю и время обновления.
Незавершённая последняя запись останавливает запуск с явной ошибкой.

React владеет service, resource и conversation client через `useOwnedClient`.
`useClientStore` читает библиотечное состояние. Replay и reconnect обеспечивает
common2; отдельной клиентской копии протокола нет. Черновик очищается после
подтверждения, повтор использует сохранённые payload и requestId.
Смена аккаунта или workspace закрывает прежнего владельца и очищает экран,
черновики и pending actions. Logout локален и не отзывает токены на других устройствах.

Владелец может менять membership через native команды, bound к workspace.
Сервер проверяет current owner и сохраняет последнего владельца. Полная native REST
отключена; HTTP оставляет только native credential login. Это временное ограничение
из-за [SERVICE-COMMAND-RECEIPT-ACL](../../doc/library-tasks/SERVICE-COMMAND-RECEIPT-ACL.md).
Подробный публичный контракт — [API](API.md).

На узком экране список чатов открывается отдельно от истории; «Чаты» возвращает
к списку. Enter отправляет, Shift+Enter добавляет строку. История прокручивается
независимо от формы; текст сообщений сохраняет переносы строк.

## Проверки и границы

`npm test` проверяет настоящие сетевые клиенты, доступ, receipts и перезапуск.
Для принятого C01 typecheck/test/build и автоматический reconnect проверены
на тех же клиентах после server restart. [Отчёт C01](../../doc/changes/chat-c01-20260926.md)
фиксирует browser сценарии и ограничения. [Паспорт](PASSPORT.md) и [STATUS](../../doc/STATUS.md).
Реализация C03 не наследует прежний PASS: ей нужна собственная runtime/browser
приёмка. [Контракт C03](../../doc/changes/chat-c03-design-20260926.md).

Это один локальный писатель и две демонстрационные учётные записи. Нет
внешнего provider, semantic streaming, удалённого агента, динамического создания workspace
или установленного desktop/mobile. Эти требования сохраняются отдельными
этапами C02–C08. Адаптивная страница не закрывает установленный mobile-клиент.
