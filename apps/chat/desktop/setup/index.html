Подключиться к Chat

Введите адрес, который выдал администратор. Аккаунт и пароль вводятся на сервере после подключения.

Только адрес сервера, без пути и завершающего /. Пример не является работающим сервером.

Приложение сохраняет только адрес. «Сервер → Сменить сервер / выйти» очищает текущую сессию. Даже прежний сервер после этого потребует новый вход.
