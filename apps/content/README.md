# Folio — контент и публикации

<!-- status:versions -->
Текущие зависимости: **common2 3.1.1 / react2 5.0.0**.
<!-- /status:versions -->

Самостоятельная небольшая студия: блоки страницы, изображения, замечания и согласование версии, расписание, публикация, откат и отзыв. Пять типов блоков — heading, text, image, quote, button — без произвольного HTML, скриптов и универсального конструктора сайтов. Authority владеет изменениями, снимками, расписанием и файлами; обслуживающие узлы отдают ролевые проекции.

## Запуск

```text
npm ci
npm run build
npm start
```

Открыть http://127.0.0.1:3817. Данные — в `content-data`; порт, адрес и каталог меняют `SERVICE_PORT`, `SERVICE_HOST` и `SERVICE_DATA_DIR`, отдельно задаются стабильные `SERVICE_TOKEN_SECRET` и `SERVICE_NODE_TOKEN`, версия образа — `APP_RELEASE`. `.env` автоматически не загружается. Для разработки — `npm run dev`.

Анонимный журнал открывается на `/#read=northstar`, статья — `/#read=northstar/welcome`.

## Роли и демоданные

| Аккаунт | Пароль | Доступ Northstar |
| --- | --- | --- |
| owner | owner-pass | Все операции и роли |
| author | author-pass | Свои черновики, изображения, отправка на согласование |
| editor | editor-pass | Черновики организации, замечания и решение |
| publisher | publisher-pass | Чтение редакторских версий, публикация, расписание, откат |
| reader | reader-pass | Публичные материалы, без черновиков, замечаний и медиатеки |
| outsider | outsider-pass | Владелец Harbor, без редакторского доступа к Northstar |

Аккаунты предназначены для приёмки, внешняя регистрация не подключена. В Northstar исходная страница `welcome` ещё не опубликована.

Сценарий: автор собирает страницу из блоков и отправляет версию на согласование, создавая неизменяемый снимок → редактор оставляет замечания к конкретному блоку и принимает решение → издатель публикует одобренную версию или ставит её в расписание → правка черновика отменяет отложенную публикацию → откат публикует прежнюю одобренную версию новой записью истории, не трогая черновик → отзыв закрывает публичное чтение.

## Границы

- Публикует один authority. Обслуживающие узлы передают публичные чтения ему и при потере связи возвращают 503, а не старую локальную публикацию.
- Публичный фасад никогда не отдаёт черновики, снимки, замечания, расписание, аккаунты и аудит. Уже отправленные до отзыва байты и копии в памяти читателя удалить невозможно.
- Публичное представление через реплики — согласованный со временем снимок для интерфейса: строгую проверку делайте через ресурс authority или HTTP.
- Изображения: PNG, JPEG и WebP до 512 КиБ, проверка по сигнатуре; SVG и HTML не принимаются, внешние URL сервер не загружает. Это не полноценный декодер и не антивирус.
- Незавершённая загрузка при сбое между записью файла и метаданных может оставить недоступные байты: общей аварийной очистки нет, и удалять файлы по одному отсутствию в черновике нельзя.
- Помощник по умолчанию — явный тестовый исполнитель (пробелы и первая буква), **не языковая модель**: предложение видно до принятия, страница меняется только явным действием человека. Платных запросов нет.
- Пределы стенда: 200 страниц, 30 блоков и 50 000 символов на страницу, 50 снимков, 100 решений, 200 замечаний, 100 публикаций и 100 расписаний на страницу, 200 активных изображений, 3000 ключей намерений, 1000 записей аудита.
- Нет публичного редактирования, внешней регистрации, инвалидации CDN, очистки истории снимков и миграции владельца файлов.

## Проверки

```text
npm run typecheck
npm test
npm run build
```

`npm test` — самостоятельные проверки домена, изображений, помощника и сети: настоящий authority с двумя обслуживающими узлами, принудительное отключение узла, отмена расписания, 503 при потере связи, просроченная публикация после рестарта ровно один раз и откат.

Размещение — `npm run test:content` из `apps/hosting`: образы `first` и `second` собираются из этого `Dockerfile` после `npm run build`, проверяются установка, обновление и откат при постоянном адресе шлюза. Публикация переживает смену релиза, вторая версия выходит поверх неё, а откат образа данные не откатывает — прежний текст возвращает команда `pageRollback`. Контейнер ограничен 256 МиБ.

`npm run test:integration` дополнительно поднимает настоящие Content и Support в исходном репозитории: чтение с учётными данными читателя, серверная привязка организаций, отсутствие черновиков и замечаний у потребителя, публикация, отзыв и откат, отказ при смене роли, отзыв членства во время чтения и недоступность источника. Эта проверка импортирует соседнее приложение и в самостоятельную копию не входит.
