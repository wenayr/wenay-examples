# Orbit — продажи и согласование с клиентом

<!-- status:versions -->
Текущие зависимости: **common2 3.1.1 / react2 5.0.0**.
<!-- /status:versions -->

Самостоятельная CRM: компании, контакты, воронка сделок, неизменяемые версии предложений, кабинет клиента, импорт контактов и связанные задачи. Суммы — условные копейки для примера, без оплаты и счетов. Поддержка, документы и пиццерия для работы CRM не нужны.

## Запуск

```text
npm ci
npm run build
npm start
```

Открыть http://127.0.0.1:3813. Данные — в `crm-data`; порт и каталог меняют `SERVICE_PORT` и `SERVICE_DATA_DIR`. Для разработки — `npm run dev`. Описание подключения публикуется по `/api/client`, библиотечные REST-команды и login — под `/api/crm`, документация — `/docs` и `/openapi.json`.

## Роли и демоданные

| Аккаунт | Пароль | Роль |
| --- | --- | --- |
| `owner` | `owner-pass` | Владелец Northstar: состав команды, все сделки и назначения |
| `lead` | `lead-pass` | Руководитель: все сделки, массовое назначение, возврат закрытой сделки |
| `manager` | `manager-pass` | Менеджер: справочники и чтение команды; изменение назначенных ему сделок |
| `customer` | `customer-pass` | Клиент: только связанные с его аккаунтом сделки и опубликованные предложения |
| `outsider` | `outsider-pass` | Владелец Harbor без доступа к данным Northstar |

Аккаунты предназначены локальному стенду. Владелец назначает роли существующим аккаунтам; email контакта — поле CRM, а не подтверждение личности. Последнего владельца нельзя удалить или понизить.

Рабочий путь: менеджер создаёт компанию, контакт и сделку с ответственным → переносит её в `qualified`, разделяя публичные сообщения и внутренние заметки → публикует неизменяемую версию предложения → клиент принимает актуальную версию или просит изменения (старую версию и устаревшую ревизию принять нельзя) → принятие создаёт **одну** задачу органайзера с двумя пунктами проверки, и повтор запроса вторую не создаёт → менеджер выполняет чек-лист и переносит сделку в `won`, а `lost` требует причины. Согласование не отправляет письма, не выполняет работу и не проводит платёж.

## Границы

- Каждая запись принадлежит организации: роли из общей сессии недостаточно, членство проверяется именно в запрошенной организации.
- Клиенту не передаются внутренние заметки, черновики, справочники и аудит; контактные email и телефон скрыты и в подробной карточке.
- Удаление заменено архивом: сначала архивируются связанные записи, исторические ссылки сохраняются.
- Помощник по сделке — **тестовая выдержка фактов, не языковая модель**; платных запросов нет, результат виден только создавшему его сотруднику и не уходит клиенту.
- Импорт CSV подтверждается построчно: отмена не откатывает уже добавленные контакты, после прерывания нужна явная сверка, а не скрытый повтор.
- Пределы стенда: 20 организаций, 1000 компаний, 2000 контактов и 2000 сделок, 200 взаимодействий на сделку, 20 версий предложения, 500 задач организации, 1000 записей аудита. Частота — 120 команд в минуту на аккаунт.
- Приватный журнал результатов помощника и checkpoint лежат в каталоге сервера: защищайте его вместе с резервными копиями.
- Подключение к Counter необязательно: при `METERING_CONNECTIONS_JSON` сводка резервирует тестовую единицу, без него CRM работает самостоятельно.

## Проверки

```text
npm run typecheck
npm test
npm run build
```

`npm test` проходит настоящий service leader: изоляция организации и клиента, уникальность и связи, архивирование и восстановление, отсутствие частичной записи в массовой операции, конфликт ревизий, неизменность опубликованного текста, отклонение старого согласования, одна производная задача, чек-лист и отзыв доступа на открытом ресурсе. Помощник проверяется управляемым локальным исполнителем: источники, скрытый результат, отмена, тайм-аут, поздний ответ, очистка ошибок провайдера, восстановление частного результата с диска — это проверка оркестрации и доступа, а не качества модели. Импорт проверяется отдельным тестом.

Холодная копия — `npm run test:backup`. Размещение — `npm run test:crm` из `apps/hosting`: first, second и откат с сохранёнными взаимодействиями, предложением, согласованием и производной задачей, контейнер 256 МиБ.
