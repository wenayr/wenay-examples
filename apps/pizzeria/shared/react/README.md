# Общие React-привязки сервиса

Оба приложения используют common2 2.18.1 и react2 3.3.0 из npm. [Результаты миграции](../../../../doc/reports/library-runtime-adoption.md).

| Элемент примера | Библиотечный механизм | Что остаётся приложению |
| --- | --- | --- |
| `useServiceSession` | `useOwnedClient`, `useClientStore`, `identity.permissions`, обновление токена | URL, получение безопасного descriptor, ключ хранения токена |
| `ServiceView` | `useClientStore` | Текст загрузки/ошибки и проверка обязательных верхних ключей после очистки проекции |
| `useServiceAction` | `useAsyncAction` | Boolean-результат, удобный формам |
| `useCommandAction` | `useServiceCommands`, `ServiceCommandCall`, `runTuple` | Boolean-результат и текст ошибки для формы |

В React-слое нет таймера опроса прав, своего reconnect, replay, блокировки конкурентного выполнения или собственного генератора requestId для команд. Новые права приходят реактивно; common2 сам обновляет фасад, очищает запрещённые представления и восстанавливает доступ при возврате роли.

`ServiceView` не создаёт зеркала и не закрывает чужое представление. `initial` задаёт только обязательные верхние ключи. Сессией владеет `useOwnedClient`, транспортом — `createServiceClient`.

Тип команды и её входа выводится из service definition. `command-action.types.ts` проверяется `npm run typecheck` и содержит отрицательные проверки неизвестного имени и несовместимого payload, а также передачу коррелированного вызова между компонентами. Тип кортежа и его выполнение теперь предоставляет библиотека; приведение generic-сигнатуры больше не требуется.

Токены разных сервисов должны иметь разные `storageKey`. Отзыв на реплике действует после получения ею обновления прав; мгновенный глобальный отзыв при сетевом разделении не обещается.

Эти же привязки используются каждой строкой обзора сети. Получение descriptor ограничено пятью секундами и отменяется при освобождении сессии. Обзор учитывает только строки с действующими правами, соединением и доступным текущим состоянием revenue. Состояние команды масштабирования ведёт `useServiceAction`; панель создаётся заново при смене заведения или токена.
