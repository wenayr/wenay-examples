# Разработка демоприложений

- Перед реализацией проверьте публичные API установленных версий `wenay-common2` и `wenay-react2` и ближайший рабочий пример. Используйте готовую возможность библиотеки, если её поведение подходит задаче.
- Предметные расчёты оформляйте функциями с явными входами и результатом. Для сервиса с состоянием используйте фабрику с замыканием и разделите интерфейс по операциям, которые нужны вызывающему коду.
- Для связанной модели определите исходные разделы и ключи один раз. Выводите идентификаторы и конкретные типы из этих данных через `keyof typeof`, `typeof` и `ReturnType`. Проверяйте таблицы реализаций или данных через `satisfies`. Обязательные и разреженные измерения таблицы типизируйте согласно предметной модели.
- В `wenay-common2/examples/pizzeria/service.ts` объект с разделами `access`, `commands` и `views` проверяется оператором `satisfies`; тип сервиса выводится из объекта. В этом репозитории пример матрицы «отель × дата вылета» находится в `apps/travel/demo/catalog.ts`.
