# Поставщики и оформление тура из Эстонии

## Доступные каналы

Каталог справочных объектов принимает внешние источники. Запись о гостинице указывает происхождение данных. Цену на проживание и наличие при переходе показывает посредник. В отдельном разделе пакетных предложений сервер проверяет Хургаду, Шарм-эль-Шейх и Родос по датам в публичном шлюзе TEZ TOUR Eesti. Пакет включает перелёт из Таллина, проживание и трансфер. Результаты бронирования и подтверждение комиссии потребуют отдельной партнёрской операции.

| Канал | Что получает посетитель | Что передаётся |
| --- | --- | --- |
| TEZ TOUR Eesti | Фактические предложения с датой, числом ночей и ценой в евро за двоих. Ссылка каждого предложения открывает публичную карточку отеля TEZ. | Из Таллина, размещение двух взрослых. По выбранным датам проверяется точная продолжительность. Без дат поиск охватывает ближайшие 20 дат вылета на 7 ночей. Положительный ответ переиспользуется две минуты с сохранением времени проверки. |
| Booking.com | Поиск подходящего отеля или курорта на площадке. | Название, направление, даты заезда и выезда при наличии, одна комната, число гостей, EUR. |
| Expedia | Поиск размещения в выбранном направлении. | Название направления, даты при наличии, одна комната, число взрослых. [Описание ссылок для размещения](https://developers.expediagroup.com/white-label-template/traffic-growth/deeplinking/lodging-deeplinks) |
| Novatours Eesti | Публичная страница туров на доступные курорты эстонского оператора. | Курорт из собственного меню Novatours. Даты, гостей и наличие посетитель уточняет на площадке. [Хургада](https://www.novatours.ee/travels/EG/HRG) · [Пхукет](https://www.novatours.ee/travels/TH/HKT) |
| Сайт гостиницы | Прямой переход из карточки, если исходный каталог предоставил HTTPS-адрес. | Указанный в источнике URL. |

Передача на сайт возможна без договора с конкретным отелем. Для вознаграждения от Booking.com нужен присвоенный этому агентству партнёрский идентификатор с применимыми условиями. Если программа выдала числовой `aid` для ссылок этого формата, его можно задать на сервере как `TRAVEL_BOOKING_AID`. По умолчанию в ссылках отсутствует партнёрский идентификатор. Ссылки Novatours и Expedia служат для публичного поиска. Денежные начисления в приложении отсутствуют.

### Проверка живой выдачи

13 ноября 2026 года сервер обратился к `https://search.tezapi.eu/tariffsearch/getResult` с параметрами Таллин → Хургада, 24–31 января 2027 года, два взрослых, 7 ночей. Поставщик вернул 62 гостиницы. Для ближайших 20 дат вылета в Хургаду получены 57 гостиниц, в Шарм-эль-Шейх — 53. Для Родоса в окне вылетов 10–28 июля 2027 года поставщик вернул 28 гостиниц. Это результаты контрольных запросов на момент проверки. Текущая выдача рассчитывается заново и может меняться. При отсутствии мест или временной ошибке пользователь может продолжить поиск у другого поставщика. Агентская ссылка создания заказа из ответа TEZ не открывается клиентом. [Европейский шлюз и условия доступа](https://www.teztour.ee/page/xml-gate.et.html) · [Параметры поиска](https://www.tez-tour.com/en/msk/article.html?id=7015573)

Режим демонстрационных пакетных туров сохранён отдельно. Кнопка в нём создаёт локальную заявку на выбранный демотариф до перезагрузки страницы.

Для карты шлюз возвращает самый дешёвый подходящий пакет каждого отеля за выбранное окно вылетов. Сервер передаёт границы бюджета до группировки и проверяет итоговые суммы в евроцентах. Для выбранного отеля и дня сервер запрашивает тарифы без группировки, поэтому график может показать и минимум дня, и другой тариф в бюджете. Например, для Sand Beach из Таллина на 24 января 2027 года при проверке 13 ноября 2026 года минимальная цена за двоих составила 1 384 евро, а при нижней границе 1 400 евро оператор предложил 1 412 евро. [Параметры группировки и фильтры](https://www.tez-tour.com/en/msk/article.html?id=7015573)

Координаты сверены по идентификаторам TEZ с картой на публичной странице каждой гостиницы. Начальная поставка содержит 3 точки в Хургаде, 5 в Шарме и 5 на Родосе. Гостиницы без координат остаются в списке тарифов. Новая область карты применяется к уже полученным предложениям. Фотографии гостиниц из тарифного ответа не копируются. [Карточка Sand Beach, ID 1061](https://www.tez-tour.com/hotel.html?id=1061) · [Происхождение точек](backend/partners/tez-locations.json)

## Роль продавца и расчёты

При продаже собственного пакета «перелёт + отель» нужно определить, кто заключает договор с туристом. Эстонский TTJA публикует требования для туроператоров, продавцов пакетов операторов за пределами ЕЭЗ и посредников по связанным туристическим услугам. Для туроператора регулятор указывает уведомление о деятельности и финансовое обеспечение с учётом установленных законом исключений. Проверка конкретной компании и модели продажи понадобится перед приёмом оплаты. [Разъяснение TTJA и ссылка на реестр](https://ttja.ee/en/business-client/entrepreneurship/traveler-trader)

Ключи поставщиков и OpenAI хранятся на сервере. Живой календарь airBaltic, поиск TEZ и переходы к другим посредникам доступны без агентских ключей. В «Моей поездке» пользователь может сверить выбранный тариф с TEZ и вручную перенести параметры заказа. При добавлении оформления веб-интерфейс и чат через MCP должны обращаться к одной операции повторной проверки выбранного тарифа. Если сумма изменилась, новый итог показывается клиенту перед заказом. Бронирование получает статус подтверждённого на основании ответа поставщика. Доход по партнёрской операции можно учитывать после сверки с отчётом партнёра по условиям договора. Расходы на вызовы OpenAI учитываются отдельно.
