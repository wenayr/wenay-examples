# Поставщики и оформление тура из Эстонии

Проверено 13 ноября 2026 года по материалам поставщиков и эстонского регулятора. На витрине используются демонстрационные цены. Кнопка создаёт заявку в памяти открытой страницы, по выбранному тарифу и полной сумме. Перезагрузка завершает демонстрацию. Заявка не отправляется поставщику, не резервирует места и не создаёт финансовых обязательств.

## Роль продавца и расчёты

При продаже собственного пакета «перелёт + отель» нужно определить, кто заключает договор с туристом. Эстонский TTJA публикует требования для туроператоров, продавцов пакетов операторов за пределами ЕЭЗ и посредников по связанным туристическим услугам. Для туроператора регулятор указывает уведомление о деятельности и финансовое обеспечение с учётом установленных законом исключений. Проверка конкретной компании и модели продажи понадобится перед приёмом оплаты. [Разъяснение TTJA и ссылка на реестр](https://ttja.ee/en/business-client/entrepreneurship/traveler-trader)

Для живого подключения ключи поставщиков и OpenAI хранятся на сервере. Веб-интерфейс и чат через MCP обращаются к одной операции повторной проверки выбранного тарифа. Если сумма изменилась, новый итог показывается клиенту перед заказом. Бронирование получает статус подтверждённого на основании ответа поставщика. Доход по партнёрской операции можно учитывать после сверки с отчётом партнёра по условиям договора. Расходы на вызовы OpenAI учитываются отдельно.
