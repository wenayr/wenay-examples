# Wenay Travel · путешествия

[Запуск и сценарии](README.md) · [Состояние каталога](../../doc/STATUS.md)

- **Сценарий:** Поиск отелей на карте, сравнение пакетных туров из Таллина, отдельные авиабилеты и подбор через чат или MCP.
- **Роли:** путешественник сохраняет отель или пакет, перепроверяет тариф и обращается к продавцу.
- **Порт:** 3820
- **Проверки:** `npm run typecheck`, `npm test`, `npm run build` проверяют типы, поставщиков, поиск, состояние и демозаявку.
- **Размещение:** `npm ci`, `npm run build`, `npm start`.

## Ограничения

Открытые реестры подтверждают справочные сведения. Пакетные цены для поддерживаемых курортов поступают из поиска TEZ TOUR. Подтверждение наличия и оформление выполняет продавец. В автономном примере заявки демонстрационные.
