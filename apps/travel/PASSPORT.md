# Wenay Travel · путешествия

[Запуск и сценарии](README.md) · [Состояние каталога](../../doc/STATUS.md)

- **Сценарий:** Поиск пакетного тура по гибким датам, карте и полной стоимости. Выбор даты и локальная демозаявка.
- **Роли:** путешественник выбирает предложение. Локальный адаптер регистрирует выбор в интерфейсе.
- **Порт:** 3820
- **Проверки:** `npm run typecheck`, `npm test`, `npm run build` проверяют типы, поиск, состояние и демозаявку.
- **Размещение:** `npm ci`, `npm run build`, `npm start`.

## Ограничения

Цены и доступность демонстрационные. Заявка остаётся в браузере. Поставщик не получает бронь, оплата и начисление комиссии не выполняются.
