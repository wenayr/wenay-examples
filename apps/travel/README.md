# Wenay Travel · туры из Таллина

В демонстрационном каталоге девять отелей в Хургаде, на Пхукете и в Пафосе. Цены в евро включают перелёт туда и обратно из Таллина и проживание двух туристов на 10 дней. Выбирайте удобное окно **вылета**: при позднем вылете поездка может закончиться в следующем месяце.

## Запуск

Нужен Node.js 24.2 или новее. Из корня репозитория:

```sh
cd apps/travel
npm ci
npm run build
npm start
```

Откройте **http://127.0.0.1:3820/**. Сервер читает сборку из `dist/`; порт можно переопределить переменной `SERVICE_PORT`. Для разработки с обновлением страницы используйте `npm run dev`. Для запуска через общую витрину откройте второй терминал в корне репозитория, запустите `node apps/catalog/server.mjs` и найдите Wenay Travel по адресу http://127.0.0.1:3800/.

## Выбор поездки

1. Задайте интересующие даты вылета и бюджет за всю поездку. Стартовый диапазон с 15 по 31 января 2027 года, от 0 до 3800 €. Каждый отель в выдаче имеет хотя бы один подходящий тариф.
2. Выберите отель на карте или откройте его карточку. На графике видны минимум дня и минимальная цена в бюджете. Если на одну дату минимальный тариф дешевле нижней границы, более дорогой тариф может подходить. Дни без предложений остаются пустыми.
3. Выберите подходящую дату. Интерфейс покажет конкретный тур и полную цену. Параметры поиска и выбор можно восстановить при следующем открытии в том же браузере.
4. Создайте демозаявку, чтобы проверить путь клиента до подтверждения выбора. Рабочие варианты подключения поставщиков описаны в [справке о партнёрах](PARTNERS.md).

Цены, доступность и предложения демонстрационные. Фотографии иллюстрируют направления. Пользователь может выбирать туры без обращения к поставщику или платёжному сервису.

## Код и проверка

```sh
npm run typecheck
npm test
npm run demo
```

- `demo/catalog.ts` связывает направления, координаты отелей и тарифы с датами вылета. Идентификаторы выведены из исходного каталога.
- `src/search-tours.ts` формирует общие для карты и графика результаты. В поисковом запросе суммы указаны в минимальных единицах валюты, для евро это центы.
- `frontend/state.ts` использует `wenay-common2/observe`, компоненты подписываются на выбранные данные через `wenay-react2/react`.
- `src/inquiry.ts` задаёт границу локальной демонстрационной заявки.

Следующий этап живой версии — подключить согласованный партнёрский канал и повторно проверять наличие и стоимость до подтверждения заказа. Веб-интерфейс и ИИ-чат смогут использовать один серверный метод поиска через MCP.
