# Мировой справочник аэропортов

Поиск по IATA, городу, названию аэропорта, стране и региону работает на локальном снимке. Например, ввод «Техас» даёт варианты DFW, IAH, AUS, DAL и HOU. После выбора аэропорта цены и наличие проверяет отдельный поиск рейсов.

Данные OurAirports распространяются как public domain. Источники — таблицы airports.csv, regions.csv и countries.csv. Снимок содержит 9 053 действующих объектов с трёхбуквенным кодом IATA, включая 4 133 с признаком регулярного обслуживания. Справочник сохраняет написание города и названия аэропорта из источника. Поддерживается поиск по дополнительным именам OurAirports, распространённым русским названиям, русским названиям стран и транслитерации. Регулярное обслуживание и размер аэропорта повышают приоритет подсказки. В крупных агломерациях редакционный список узлов помогает сортировке. Эти признаки не определяют доступность конкретного маршрута.

## Сборка снимка

Из корня примера Travel выполните `python3 scripts/prepare-airports.py`. Скрипт использует стандартную библиотеку Python 3, загружает три CSV закреплённой ревизии и атомарно заменяет `backend/flights/airports.json.gz`. Для обновления передайте `--revision` с полным идентификатором коммита OurAirports. Параметр `--source-dir` принимает каталог с тремя заранее загруженными CSV той же ревизии. Отметка времени в gzip фиксирована для повторяемой сборки. Сервер читает снимок при первом запросе и повторно использует построенный индекс.
