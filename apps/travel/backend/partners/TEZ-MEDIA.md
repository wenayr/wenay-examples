# Фотографии каталога TEZ

`tez-media.json` связывает фотографии с числовым идентификатором отеля в предложениях TEZ. Запись хранит имя объекта, его `SITE_HOTEL_ID`, исходную страницу, публичную галерею и до пяти проверенных изображений.

Сборщик сначала сверяет `HOTEL_ID` страницы с запрошенным объектом. Значение `SITE_HOTEL_ID` определяет галерею `siteGalleries.html` и допустимую папку `hotel/{siteHotelId}` на `s.tez-tour.com`. Главная фотография и следующие опубликованные изображения выбираются из этой галереи. Названия, ведущие в другую папку, обходы путей и неподходящие форматы отклоняются.

Размер `middle` формируется тем же правилом, которое применяет публичный скрипт страницы TEZ. Каждая сохранённая фотография получила HTTP 200, MIME JPEG/PNG/WebP и непустое тело ответа. Статус, объём и время проверки сохранены у изображения. Дата съёмки источником не устанавливается.

Для обновления выполните из `apps/travel` команду с каталогом кэшированных страниц.

```sh
node scripts/collect-tez-media.ts --destination hurghada \
  --cache ../../artifacts/hurghada-geo \
  --output backend/partners/tez-media.json
```

Сборщик переиспользует страницы и галереи из кэша. `--refresh` заново получает их у поставщика. Галереи обрабатываются четырьмя параллельными задачами, изображения — шестью. Манифест заменяется атомарно после завершения. Неподтверждённые объекты попадают в `unresolved` с причиной. Рабочие данные операторских цен и координат сборщик не изменяет.

Подпись изображения и ссылка источника доступны интерфейсу. Значение `rights: supplier-permission-required` фиксирует необходимость согласовать коммерческий способ использования материалов с поставщиком. Запись о публичной галерее сохраняет происхождение изображения. Порядок согласования медиа входит в [подключение B2B-поставщиков](../../docs/B2B-ONBOARDING.md).

Браузер загружает только изображения показанных карточек и выбранной галереи. Манифест содержит URL, а не локальные копии фотографий. При временной сетевой ошибке интерфейс сохраняет имя отеля и возможность открыть исходную карточку.
