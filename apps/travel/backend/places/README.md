# Каталоги размещения

Каталог включает картографические точки размещения и записи реестров. Наличие номера, доступность для конкретных дат и договор с объектом подтверждает коммерческий поставщик. Метаданные `price` и `photo` этих трёх источников равны `null`. Фотографии с собственной подтверждённой лицензией подключаются отдельно.

| Источник | Что отбираем | Источник и лицензия |
| --- | --- | --- |
| OpenStreetMap contributors | Именованные гостиницы и другие типы размещения внутри прямоугольника курорта. У полигонов координата соответствует центру ограничивающего прямоугольника. | [Данные OpenStreetMap](https://www.openstreetmap.org), [ODbL 1.0](https://www.openstreetmap.org/copyright), [условия общих серверов Overpass](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html) |
| Wikidata | Объекты с классом гостиницы или производным классом и координатами в регионе. Исключены известные даты ликвидации и прошедшая дата закрытия. | [Сервис SPARQL](https://www.wikidata.org/wiki/Wikidata:SPARQL_query_service), [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing) |
| Fáilte Ireland | Отели, B&B, хостелы, гостевые дома и апартаменты с регистрационным номером и координатами из национального реестра Ирландии. | [Государственный реестр и API](https://data.gov.ie/dataset/national-quality-assurance-framework-register-of-accommodation), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |

Каждый файл в `snapshots` — отдельная адаптированная выборка указанного источника. Для выборок OpenStreetMap действует ODbL 1.0, для выборок Fáilte Ireland действует CC BY 4.0. Формат изменён. В рабочем контракте сохраняются идентификатор, происхождение и разрешённые сведения записи. Интерфейс указывает исходный каталог и его лицензию. Соответствие между поставщиками служит навигацией между записями; исходные выборки и их лицензии остаются доступными независимо. Имена владельцев и контакты физических лиц из реестра Fáilte Ireland не импортируются. Время `fetchedAt` обозначает момент получения выборки. При успешном ответе с пустым списком время также сохраняется. Отсутствие полученной выборки обозначается значением null. Записи могут отставать от реального состояния гостиницы.

## Обновление

Из `apps/travel`:

```sh
node backend/places/refresh.mjs
node backend/places/refresh.mjs wikidata phuket
node --test backend/places/places.test.mjs
```

Загрузка разрешена только для регионов в `registry.mjs`. Ограничения одного ответа: до 1000 объектов OpenStreetMap и 350 строк Wikidata до удаления повторов. Отсутствие гостиницы в выборке не определяет её наличие или статус бронирования. CLI обновляет снимки атомарно. При сетевой ошибке ранее сохранённая выборка остаётся на диске. При массовом запуске на один источник приходится один одновременный запрос. Ответ HTTP 429 останавливает оставшиеся запросы к этому источнику в данном запуске. Для регулярного коммерческого трафика учитывайте рекомендации оператора общего сервера Overpass о собственной инфраструктуре.
