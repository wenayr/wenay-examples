# Страница отеля и вход в раздел

Название отеля на карте открывает одну большую страницу: галерея фотографий, матрица
цен, сведения поставщика, отзывы. Нажатие миниматрицы открывает эту же страницу сразу
на матрице; навигация «Фотографии / Даты и цены / Об отеле / Отзывы» не создаёт новый
стек окон. Кнопки расположения на карточке и странице возвращают к точке отеля.

Маршрут сохраняет `hotelSection=gallery|matrix|information|reviews` вместе с отелем,
датами, длительностью, выбранным тарифом и камерой карты. Прежние ссылки
`priceView=matrix` без `hotelSection` продолжают открывать матрицу. Выбор раздела
заменяет текущий URL, а Back закрывает страницу, сохраняя последний выбор поездки.

Используется один native dialog и собственный scroll-container. Галерея имеет
зарезервированную responsive высоту ещё до ответа фотоисточника. `useLayoutEffect`
открывает dialog, задаёт scrollTop нужного раздела с учётом sticky header и фокусирует
раздел с `preventScroll` до первой отрисовки. Видимого smooth-scroll/таймера после
открытия нет. ResizeObserver сохраняет исходный якорь при загрузке фото, имени,
сведений или цен, пока пользователь сам не начал прокрутку/взаимодействие.

Матрица остаётся основным видом цен. Дополнительный график для одной длительности
свёрнут ниже неё. Календарный запрос запускается только для раскрытого графика либо
подтверждения явно выбранного тарифа без соответствующего снимка матрицы; обычное
открытие галереи не добавляет ещё одно окно ценовых запросов.

## Карточка на карте

- Название открывает страницу отеля, миниматрица — раздел цен.
- На компьютере карточка переносится за фотографию после порога 4px; стрелки листают
  фотографии. Кнопки управления не запускают перенос.
- На телефоне горизонтальный свайп по фото меняет кадр; перенос доступен за захват
  слева сверху. Свайп фотографии не двигает карточку.
- Захват остаётся доступен с клавиатуры. Во время pointer gesture обновление цен не
  отсоединяет захваченный DOM-элемент, а завершение/cancel/unmount освобождают захват.
- Слева снизу фото — расположение на карте, справа сверху — закрытие. Семь нижних
  иконок, фото 134px, карточка 190×244 и миниматрица 170×20 сохраняются.

## Источники сведений

Большая страница запрашивает `package-gallery?hotelId=...&details=1`. Обычная галерея
карты не включает этот флаг и не делает новые запросы HTML для всего viewport.
Сведения берутся из той же страницы TEZ, которая уже используется для метаданных,
после проверки точного HOTEL_ID. В ответе — короткие структурные факты, дата проверки,
источник и ссылка сайта из контактов поставщика. Длинные описания и отзывы не копируются.

Поставщик может сообщить расположение «на берегу моря», расстояние до аэропорта/центра,
год открытия/реновации и число номеров. Неподтверждённые параметры не выдумываются:
«на берегу» не превращается в 0 метров до пляжа, отрицание и неподдержанный диапазон
не превращаются в положительный точный факт. При сбое сведений прежние фотографии
сохраняются. Страница у поставщика и сайт отеля подписаны раздельно.

Отзывы используют прежний источник Expedia Rapid и проверенные внешние ссылки;
отсутствие ключей или сопоставления не подменяется выдуманными отзывами.
