## Копия и восстановление данных

Общая приёмка продукта дополнена строкой: холодная копия каталога данных снимается и восстанавливается в новое место, после чего сервис запускается на восстановленных данных и отдаёт прежние записи. Инструменты — `scripts/backup.mjs` и `scripts/restore.mjs`, живая проверка приложения — `npm run test:backup`. Состояние по каждому приложению видно в колонке «Копия» файла [STATUS](STATUS.md); подробности и границы — [отчёт](reports/backup-restore.md).
