# 0.1.0 — Пиццерия

- Добавлено приложение apps/pizzeria: Node-сервер на wenay-common2, React-интерфейс с replay/store hooks wenay-react2.
- Вход и регистрация, корзина, оформление и отмена заказа, кухня, доставка, управление меню и ролями, выручка.
- Сервер проверяет роли, принадлежность заказа и переходы состояния; приватные данные передаются отдельными replay-линиями.
- Состояние и receipts сохраняются в файловом архиве common2.
- Зависимости установлены из npm registry: wenay-common2 2.16.0, wenay-react2 3.1.0. Локальные библиотеки не нужны.
- Проверены типы, production-сборка, серверный сценарий через реальные процессы и вход/оформление заказа в браузере.

Оставшиеся проверки текущей реализации: перезапуск с архивом, reconnect браузера, полный визуальный проход рабочих ролей. Это учебное приложение с демонстрационными учётными записями, без платёжного провайдера.
