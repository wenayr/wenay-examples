# 0.10.0 — обзор сети на общих React hooks

Первый этап [дальнейшего плана](../NEXT-STEPS.md) завершён. Точные npm-зависимости остаются wenay-common2 2.18.1 и wenay-react2 3.3.0; новые пакеты не добавлены.

Каждая строка заведения владеет своей сессией через `useServiceSession`/`useOwnedClient`, читает выручку через `useClientStore` и передаёт в сводку только доступное текущее значение. Массив ручных клиентов и подписок удалён. Отзыв прав и потеря соединения исключают строку из общей суммы; доступ и охват показаны явно.

Масштабирование использует общий action hook. Панель привязана к заведению и токену; устаревший ответ не изменяет панель после переключения. Незавершённые чтения отменяются при уходе, получение descriptor ограничено пятью секундами. Отмена клиентского запроса не откатывает уже принятое сервером масштабирование.

## Проверки

- `npm run typecheck`, `npm run build`, `npm run build:organizer` — успешно.
- `npm run test:network` — успешно: независимые процессы, изоляция токенов/данных/фотографий, отказ serving node, масштабирование, восстановление архива и топологии. Scale-to-zero с переходом на основной процесс — 2069 мс.
- Отдельная тестовая сеть с двумя заведениями: доставленный заказ в «Центре» добавил 9 € в обзор открытого «Севера» без обновления страницы.
- Отзыв роли владельца «Центра» убрал его выручку: 0 €, охват 1 из 2. Возврат роли восстановил 9 € и 2 из 2 без refresh. Исходные роли тестовых аккаунтов восстановлены.
- Обновление обзора сохранило две строки и правильную сумму. После выхода из «Севера» вход в «Центре» сохранился, строка «Севера» требует входа, охват — 1 из 2.
- Во время увеличения числа узлов «Центра» с 1 до 2 выполнен переход в «Север»: его панель осталась на одном узле. При возвращении «Центр» показывает два работающих узла.
- Консоль браузера после сценариев — без ошибок и предупреждений.

Полный `npm test` выполнялся для 0.9.0; в этом этапе повторён целевой сетевой тест. Длинная доска, удержание у края, реальное touch-устройство и минимальный новый сервис остаются следующими этапами.

## Польза библиотек

Повторное применение уже опубликованных lifecycle/store/action hooks позволило убрать ручное управление клиентами и подписками ещё из одного экрана. В приложении остались выбор заведений, правила включения выручки в сумму и форма масштабирования. Новых требований к API библиотек этот этап не выявил.
