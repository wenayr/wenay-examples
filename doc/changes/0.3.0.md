# 0.3.0 — Сеть пиццерий

- Общие правила перенесены в `doc/CODE-RULES.md`, добавлен корневой `AGENTS.md` и общий план `doc/ROADMAP.md`.
- `npm run start:network` запускает общий интерфейс, независимые authority заведений и serving nodes. Состояние, receipts и ключи изолированы, конфигурация сохраняется.
- Выбор заведения доступен всем ролям; сессии и корзина разделены по заведению. Владелец меняет количество реальных узлов от 0 до 8.
- Интерфейс использует существующий клиент на публичных механизмах common2, а не прямое соединение только с authority. Сервер отдаёт компактный descriptor без предметных функций и исходных секретов.
- Исправлены переключение независимых проекций replay и выбор следующего endpoint после остановки узлов. Подготовлено воспроизводимое задание для исходного библиотечного scaffold.
- HTTP CORS согласован с разрешёнными origin для общего интерфейса. RPC и серверная проверка ролей сохранены.
- Проверены процессы, изоляция данных/токенов, переподключение, масштабирование, остановка одного заведения, восстановление архива/receipts и всей топологии; браузерный заказ через клиента, повара и курьера и управление узлами владельцем.

Границы: локальная оркестрация; один writer на заведение, без автоматической передачи владения. Общая выручка сети и обновление открытых фасадов при смене ролей остаются в плане.
