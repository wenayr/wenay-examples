# 0.4.0 — Все роли и оценка библиотек

- Владелец получает живую сводку выручки авторизованных заведений с явным охватом и состоянием связи.
- `identity.me()` возвращает текущие права; интерфейс пересоздаёт клиент при их изменении без повторного входа. Закрытые проекции проверяют роли по локальному состоянию и очищаются после отзыва доступа.
- Клиент продлевает сессию и при начальной авторизации готовым токеном; обновлённый токен сохраняется в браузере.
- Кнопки завершения приготовления и доставки доступны назначенному исполнителю. История заказа сохраняет принятую цену и состав; выручка по дням относится к дате доставки.
- Пройдены пять ролей в отдельных вкладках, включая порчу зарезервированного сырья, нехватку, пополнение и завершение того же заказа, создание и скрытие блюда, смену прав, обзор двух заведений и запуск узла.
- Успешны typecheck, полная серия серверных/сетевых проверок и production build. Добавлены проверки отзыва закрытой проекции и продления короткого токена.
- Подготовлены [оценка библиотек](../reports/pizzeria-library-assessment.md) и задание по жизненному циклу сессии. Зависимости остаются common2 2.16.0 / react2 3.1.0 из npm.
