# 0.6.0 — Органайзер команды и common2 2.16.1

- Общая фабрика задач и сотрудников, встроенная в пиццерию и доступная отдельным процессом на порту 3600. Оба режима используют один компонент доски и общий существующий service host.
- Перенос карточек внутри/между колонками через публичный `useReorderBoard` react2, исполнитель, срок, приоритет, описание, фильтр, карточки работников, должность и права. Есть перемещение без мыши через поле статуса.
- Серверная проверка ролей, ревизия задачи и применение относительного порядка защищают от устаревших изменений без перезаписи всей доски. Владелец создаёт аккаунты и меняет роли; менеджер управляет работой.
- В пиццерии автоматически создаются карточки приготовления, доставки, нехватки и просрочки. Состояние следует источнику; ручные задачи могут ссылаться на заказ. Старые данные сохранены миграцией до версии состояния 4.
- Установлен опубликованный `wenay-common2@2.16.1`, npm latest проверен. Клиент принят из обновлённого scaffold вместо локальной реализации обхода отказавших узлов; сохранены descriptor, health, текущие права и продление токена. React2 остаётся 3.1.0, новых зависимостей нет.
- Typecheck, весь набор проверок, обе production-сборки и браузерные сценарии прошли. Доска проверена при смене serving node; автономный архив — при перезапуске.

Подробности, команды запуска и ограничения: [органайзер](../../apps/pizzeria/organizer/README.md).
