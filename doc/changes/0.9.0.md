# 0.9.0 — публичный runtime и завершение миграции библиотек

Оба приложения используют точные опубликованные **wenay-common2 2.18.1** и **wenay-react2 3.3.0**. Поддержка массивов объектов восстановила сохранение рецептур и непустых чек-листов без обходов типизации или валидации.

- Удалены 8 скопированных файлов runtime — 2310 строк. Клиент, descriptor, definitions, сервер и host подключаются через публичные экспорты.
- Процессы и бинарные файлы используют библиотечные ресурсы. Сохраняются URL старых фотографий, ограничения загрузки и предметные права.
- Сеть исключает выводимые узлы до их остановки: scale-to-zero и переход к leader заняли 2071 мс в интеграционном сценарии.
- Органайзер использует кнопку переноса, клавиатуру, объявления позиции и опциональную автопрокрутку. После подтверждения сервером фокус возвращается на ручку. Команды передаются через ServiceCommandCall/runTuple без прежнего приведения типов.

Проверки: typecheck, полный npm test (склад, host, REST/RPC, роли, сеть, самостоятельный органайзер), обе production-сборки. В браузере созданы новое блюдо с двумя ингредиентами и задача с непустым чек-листом; проверены публичное меню, запрет преждевременного завершения и завершение после проверки. Консоли без ошибок.

Точные границы и результаты каждого пункта: [отчёт внедрения](../reports/library-runtime-adoption.md). Удержание у края с автопрокруткой и реальное touch-устройство отдельно не подтверждены. Новых блокеров нет.
