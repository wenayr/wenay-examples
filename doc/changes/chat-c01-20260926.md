# C01 — обычный web-чат «Рядом»

26 сентября 2026. `codex/unified-chat`, база принятого графического этапа G04 `4ff49d2`.
Точные опубликованные common2 3.1.1 / react2 5.0.0, самостоятельный `apps/chat`.

Обычная отправка сохраняет сообщение; явная кнопка добавляет законченный тестовый ответ.
Два клиента читают одну серверную историю. Один authority conversation host, persistence port
записывает event и receipt вместе с fsync; native common2 отвечает за replay и reconnect.
Платных AI-вызовов нет. React владеет service/resource/conversation по поколениям.

## Выполненные проверки

Typecheck 0,9 с, real-network test 8,1 с, build 2,2 с. Логи — `work/run-all/chat-*.log`.

- Независимые Alice/Bob RPC-клиенты: общая история и semantic events, private ACL.
- Durable receipts ограничены аккаунтом; повтор возвращает прежний результат. Изменённый
  payload и другой вид команды с прежним ID запрещены, в том числе при одновременных вызовах.
- Последнее доступное место при concurrent create получает один запрос и один durable commit.
- Потеря успешного ответа моделируется его отбрасыванием после подтверждённого fsync;
  это не разрыв сети между commit и ответом. Повтор и restart возвращают прежний ID.
- Настоящий server restart на прежнем port/data/secrets с теми же service clients и controllers:
  offline очищает старое поколение; automatic reconnect восстанавливает 17 сообщений без
  дублей, private ACL и receipt; новое сообщение доставляется обоим без login/open вызовов.
- Дополнительный cold restart сохраняет комнаты, каналы, demo receipt и время обновления.
  Отзыв членства закрывает удержанные команды и keyframe, resource.current становится null.

Дополнительный browser restart на прежнем endpoint/data/secrets: offline очистил историю,

## Обнаруженные ограничения библиотек

[CONVERSATION-RECEIPT-POLICY](../library-tasks/CONVERSATION-RECEIPT-POLICY.md):
старый receipt может вернуть прежнюю приватную сущность после запрета текущей policy.
Серверный wrapper проверяет текущий доступ к исходному результату до native retry.

[CONVERSATION-RESOURCE-LIFECYCLE](../library-tasks/CONVERSATION-RESOURCE-LIFECYCLE.md):
native close/revoke даёт необработанную ошибку async replay за пределами catch.
Native repro exit 1; dispose-before-end контроль exit 0. Adapter и runtime revoke приложения
прошли; библиотека не объявлена исправленной. После опубликованного исправления повторить
оба repro, обновить точные версии и удалить заменённый обход.
