# C03: аккаунты и рабочие пространства

26 сентября 2026. Продолжение принятого C01 `f083593` в `codex/unified-chat`.
Основания: [план](../AI-CHAT-PRODUCT-PLAN.md), [дизайн](chat-c03-design-20260926.md).

## Реализованная граница

Два фиксированных пространства используют отдельные native conversation hosts и журналы.
Team сохраняет прежний C01 journal, включая личный разговор Алисы и receipts;
Personal создаётся отдельно. Public service version 2 migrate добавляет membership.
Представление возвращает объект `{workspaces: [...]}`: корневой массив не соответствует
native lazy view mirror. Типы и потребители выводятся из этого контракта.

Owner-команды привязаны к точному пространству, защищают последнего владельца и проверяют
текущую роль до native RPC receipt. Replay guards проверяют доступ и lifecycle до/после
чтения; native metadata и подписки сохраняются. Второго replay или receipt ledger нет.
Стандартные HTTP commands отключены из-за подтверждённого
[SERVICE-COMMAND-RECEIPT-ACL](../library-tasks/SERVICE-COMMAND-RECEIPT-ACL.md);
HTTP вход остаётся native, с изолированным login-only mount.

Смена аккаунта закрывает conversation consumer, resource и service, очищает локальный
токен и создаёт новую сессию. Она не отзывает токен всех других устройств.
Workspace remount очищает черновик, выбор разговора и pending UI; поздние callbacks
ограждены ownership/epoch. Потеря owner закрывает membership panel вместе с её action scope.

## Ограничения

Это локальный plain web этап C03. Динамическое создание пространств, внешний identity
provider, semantic AI stream, удалённые операции и установленные desktop/mobile ещё
не приняты. Отдельный общий gate перед main обязателен: прежний C01 check:all имел
37 PASS из 39 шагов, hosting skipped из-за отсутствующего daemon, Catalog build отсутствует.
Пропуск Docker не принимается как PASS. Native дефекты библиотеки не объявлены исправленными.

Следующие этапы: C-OPT-CHAT после сохранения этого результата, Q05 public processing
feasibility, затем scoped Documents; интеграция актуального Support и общий gate.
