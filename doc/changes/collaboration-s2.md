# S2: совместное перемещение и свободная доска

10 сентября 2026. Опубликованные `wenay-common2@2.19.0` / `wenay-react2@3.3.0`, без новых зависимостей и локальных подмен библиотек.

## Результат

Оба режима органайзера используют общий компонент: видны промежуточное движение чужой задачи, место вставки и одновременный захват. Фильтр, смена вкладки, скрытие страницы, потеря подключения и устаревшая ревизия отменяют локальный жест. Чужое движение не меняет порядок: окончательная команда проверяется сервером один раз. Приватные задачи и недоступные якоря вставки исключаются серверной проекцией.

«Свободная доска» содержит заметки с текстом, цветом, размером и положением, а также направленные связи. Все сотрудники видят и редактируют эту общую поверхность; клиент пиццерии доступа не имеет. Мышь использует `useDraggableApi`, клавиатура — небольшой локальный адаптер: Пробел/Enter, стрелки, Shift и Escape. Одновременные изменения одной заметки разрешаются проверкой ревизии: проходит первая актуальная команда, вторая получает конфликт. Разные заметки редактируются независимо. Удаление заметки удаляет её связи одной командой.

Предел первого среза: канва 1600×1000, до 100 заметок и 300 связей, текст до 2000 символов. Это общие заметки сотрудников, без приватности отдельных заметок, совместного редактирования символов, масштабирования канвы и истории undo. Демонстрация экрана относится к следующему S3.

Архив standalone обновляется с версии 1 до 2, пиццерии — с 4 до 5; существующие данные сохраняются. Receipts предотвращают повторное создание. Временные координаты живут в SC1-ресурсе, отдельно от архива. После перезапуска ресурса старый drag не восстанавливается.

## Проверки и измерения

- Полный `npm test` прошёл: роли, склад, настоящие сетевые процессы, репликация, органайзер, PC1/PC2, SC1 и canvas. После усиления сценария рестарта с активным drag повторно прошёл `test:collaboration`.
- `test:canvas`: миграция старого архива, сохранение после рестарта, receipts, конкурирующие ревизии, независимые заметки, границы размеров/координат, связи, удаление, отсутствие durable-изменений от preview и запрет клиенту пиццерии.
- В браузере owner/worker: чужой preview и место вставки, одновременный захват задачи, успешный commit и отмена устаревшего жеста, Escape без сохранения; заметки мышью и клавиатурой, связи и повторное открытие. Фильтр отменяет task drag. Консоли проверенных сессий без ошибок.
- Отдельная доска с 24 задачами: клавиатурный перенос до позиции 16, Escape и фильтр. Исправлена прикладная видимость назначения: колонки ограничены по высоте, место вставки прокручивается в видимую область (в проверке scrollTop 3102 при высоте 468).
- RPC-нагрузка: 250 запросов за около 1,08 с, 10 принятых, 9 изменившихся проекций, 4950 байт их JSON. Это размер состояния, без сетевого обрамления Socket.IO. Повтор одинаковой проекции не вызывает обновление Store; durable-состояние не изменилось.
- Браузерный замер на двух заметках: 400 запросов за 6133 мс, 67 принятых. React Profiler в development: около 22 commits за 2 с активного движения, суммарно 25,3–25,4 мс, максимум 1,7 мс на commit; в покое 0 commits за 2 с. Это измерение одной сцены, не обещание FPS или нагрузки большой команды.
- Итоговые typecheck и обе production-сборки прошли. Предупреждения Vite о размере JS (>500 КБ) и будущей загрузке конфигурации остаются; ошибки сборки отсутствуют.

Проверки запускались последовательно без новых Docker/VM/Kubernetes. Реальное touch-устройство, длительное удержание указателя у края по обеим осям и большой коллектив остаются расширенными проверками; короткий mouse drag и клавиатура их не заменяют.

## Воспроизведение

Из `apps/pizzeria`: `npm run test:canvas`, `npm run test:collaboration`, `npm run build:organizer`. Для 24 тестовых карточек — `npx tsx organizer/long-board-preview.ts`, открыть напечатанный адрес и войти `owner / owner-pass`. Данные находятся в памяти и не меняют пользовательский архив.

Опциональные метрики: development-сборка органайзера и URL с `?measure-board`; React Profiler пишет `[board-render]` в консоль. `npx tsx organizer/measure-activity.ts http://localhost:<порт>` создаёт только временное движение первой заметки от демо-сотрудника; сначала создать заметку через интерфейс. Не применять к рабочему сервису. После измерения восстановить обычную `npm run build:organizer`. В production Profiler не включается. При Vite proxy задать `SERVICE_UPSTREAM`, а backend явно разрешить origin dev-сервера через `SERVICE_CORS_ORIGINS`.

## Польза библиотек и пакет изменений

common2 предоставил роли, RPC, receipts, архив, replay, serving nodes и владельца защищённого ресурса. react2 предоставил перенос колонок, mouse/touch drag, владение клиентом, подписку Store и команды. Нового транспорта или схем в приложении нет. Оставшийся код в основном описывает заметки, права, конфликт ревизий и представление чужого движения. Экономия времени в процентах не измерялась.

Новое предложение только одно: [R4 — общий клавиатурный адаптер свободного drag](../library-tasks/react-free-drag-keyboard.md). Это улучшение композиции, не дефект mouse/touch API. Новых задач common2 из S2 нет; H1/H2 хостинга остаются. Универсальный графический редактор, предметные права и протокол координат не передаются библиотекам. [Актуальный пакет](../library-tasks/CURRENT-HANDOFF.md).
