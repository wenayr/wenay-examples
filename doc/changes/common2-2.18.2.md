# Принят common2 2.18.2

10 сентября 2026 года. Точная опубликованная версия установлена в `apps/pizzeria` (включая самостоятельный органайзер) и `apps/hosting`; package.json и package-lock.json обновлены. `wenay-react2` остаётся 3.3.0 и использует тот же deduped common2 2.18.2 в каждом приложении. Локальных сборок или правок node_modules нет.

## Что закрыто

| ID | Подтверждение |
| --- | --- |
| PC1 | После close одиночная/пакетная публикация и signaling возвращают false без эффекта. Ожидавший authorize сигнал также не доставляется. Проверено локально и через настоящий RPC. |
| PC2 | Peer client.close → hub.close больше не оставляет необработанных RPC_ABORT. Прошли независимый shutdown-only и полный сетевой сценарии. |
| H0 | Опубликованный STORE-CONSUMER-GUIDE содержит раздел «A reconciliation pass across await»: живое state, отдельный вложенный snapshot и проверка актуального состояния перед внешним действием. |

Добавлен `npm run test:peer` и включён в обычный `npm test` пиццерии: положительные peer-контракты, локальная и сетевая regression-проверки в режиме `--expect-fixed`. Исторические `repro:*` без этого флага сохранены для воспроизведения на 2.18.1; на исправленном релизе их прежние ожидания намеренно не подходят.

## Проверки

- Пиццерия/органайзер: typecheck, полный npm test и обе сборки прошли. Проверены роли, склад, рецептуры, процессы, REST/RPC, независимые заведения, настоящий serving-node failover, архивы/receipts, органайзер и peer-сценарии. Planned scale-to-zero + fallback: 2071 мс в этом прогоне.
- Хостинг: typecheck, test:library-audit, полный npm test и build прошли. Сеть common2 и HTTP gateway настоящие; Docker/LXD в этом прогоне представлены HTTP fixtures. Реальный Docker и VM повторно не запускались.
- `npm ls` в обоих приложениях подтвердил common2 2.18.2 и react2 3.3.0 без второго экземпляра common2.
- Все проверки/сборки выполнялись последовательно. Новые контейнеры и тяжёлые среды не создавались; работающие preview не перезапускались. Новая браузерная приёмка интерфейса не проводилась: функциональные изменения UI этим обновлением не вносились.

## Что осталось

В опубликованном `doc/changes/2.18.2.md` явно указано: SC1/H1/H2 пока предложения, нового session/resource API нет. Проверенные definition/host/client это подтверждают. Нельзя считать внутренний документ планирования библиотеки готовой публичной интеграцией.

В [едином пакете](../library-tasks/CURRENT-HANDOFF.md) остались три предложения: SC1 — дополнительные защищённые фасады в service-сессии; H1 — повторная сверка состояния; H2 — владение ресурсами агентов. PC1/PC2/H0 отмечены закрытыми. Новых задач react2 этот проход не выявил.

Следующий шаг совместной доски — решение SC1 публичным контрактом либо поддерживаемой композицией текущих API, затем presence/курсоры/фокус в самостоятельном и встроенном органайзере. Обычная доска работает, S1 в UI ещё не подключён.
