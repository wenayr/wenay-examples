# Переработка интерфейсов примеров — 12 ноября 2026

## Объём и границы

Обновлены 12 приложений, включая витрину, и отдельный интерфейс органайзера пиццерии.
Первый проход исправил читаемость, тексты и состояния. Второй перестроил рабочие экраны:
очередь, этапы процесса, ближайшие действия и выбранный объект теперь составляют одну композицию.
Сводки вычисляются из доступных роли данных; вымышленные показатели не добавлены.

На основных рабочих экранах увеличены текст и подписи. Уточнены действия,
фокус, узкие экраны и локальная прокрутка. Загрузка, пустая выборка, отсутствие доступа,
ошибка подключения и восстановление связи получили отдельные пояснения.
Бизнес-тексты описывают результат для пользователя; технические ограничения остаются явными.

Backend, shared-механизмы и опубликованные `wenay-common2` / `wenay-react2` не изменены.
Новые зависимости и параллельные транспорт, роли или управление состоянием не добавлялись.
Реальные команды и библиотечные фасады сохранены; подробности находятся в README приложений.

## Рабочие композиции

| Приложение | Изменение |
| --- | --- |
| Catalog | 11 продуктовых карточек и органайзер внутри пиццерии; поиск, категории, сценарий, роли, запуск и ограничения. Сохранённый результат проверки отделён от доступности сервера. |
| Pizzeria | Меню рядом с закреплённой корзиной, цены и итог; путь от выбора блюда к заказу и текущему этапу. История раскрывается отдельно. |
| Organizer | Доска, фильтры, ближайшие сроки и загрузка исполнителей; чат и совместный просмотр в раскрываемой области. |
| Support | Очереди первого ответа, просрочки и назначения; список обращений, переписка и действия. Для клиента — его обращения. |
| Documents | Этапы обработки фильтруют очередь; следующий шаг ведёт к документу, результат и источник доступны рядом. |
| Metering | Подтверждённый расход, резерв и остаток; очередь неопределённых исходов и истекающих ключей с переходами к действиям. |
| CRM | Суммы и количество сделок по этапам, фильтруемая воронка; ближайшие действия открывают конкретную сделку. |
| Booking | Услуга → календарь → постоянная сводка записи; доступные слоты и переход к подтверждению удержанного времени. |
| Forms | Поиск форм; вопросы → публикация → ответы, состояние приёма и реальные счётчики версий. |
| Monitoring | Сервисы рядом с открытыми инцидентами и проверками без свежего результата; переход к измерениям выбранного сервиса. |
| Content | Черновики → проверка → согласование → расписание → выпуск; поиск, отдельные список и детализация, контекст текущей версии. |
| Approvals | Очередь ближайших решений, фильтры этапов и выбранная заявка с автором, версиями и историей. |
| Hosting | Проект → окружение → версия → результат; фактические количества, состояние операций и действия с учётом роли. |

## Исправления по review и браузеру

- Support, Documents и CRM: повтор подключения использует актуальный `liveToken` после обновления токена.
- Documents: исправлены выход таблиц за ширину страницы и слишком узкие ячейки на телефоне.
- Metering: доступный остаток для новой операции относится к текущему месяцу, независимо от исторического фильтра.
- Hosting: ближайшее действие учитывает права роли; пустой список проектов не обращается к отсутствующему проекту.
- Hosting: инструкция запуска указывает настройку аккаунтов и двух секретов до `npm start`.
- Booking: единственная услуга занимает компактную строку; заголовок больше не удерживает пустые колонки сетки.
- Формулировки счётчиков Forms и Pizzeria не зависят от склонения числительных.
- Три исторические ссылки в `APP-SHELL-PLAN` на отсутствующий worktree заменены описанием исторических путей.
