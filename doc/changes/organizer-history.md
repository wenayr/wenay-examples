# История organizer

Абзацы, ранее стоявшие в README приложения. Актуальное состояние — [README](../../apps/pizzeria/organizer/README.md) и [STATUS](../STATUS.md).

Текущие зависимости: **common2 2.21.0 / react2 3.4.0**. [H1/H2 приняты, проверки приложений и агентской оркестрации прошли](../../doc/changes/common2-2.21.0.md). Накопленный пакет библиотечных заданий закрыт. Следующие абзацы сохраняют историю внедрения.

Текущая база: common2 **2.20.0**, react2 **3.4.0**. [H3/M1/A1 приняты](../../doc/changes/common2-2.20.0.md). Состояние ИИ сохраняется в `SERVICE_DATA_DIR/chat/ai/runs.replay`; незавершённая обработка отображается как требующая сверки и не запускается повторно. `test:ai-persistence` проверяет восстановление, включая принудительное завершение процесса, без платных вызовов. Ниже описание возможностей и история предыдущих этапов.

- `wenay-react2@3.4.0`: `useReorderBoard` рассчитывает геометрию, предоставляет button activator, клавиатурный перенос и опциональную автопрокрутку; `useClientStore` связывает UI с replay-зеркалом. `useOwnedClient` владеет сессией, `useServiceCommands` — выполнением команд.
- `wenay-common2@2.19.0`: публичные definition/client/server/host, authority, RPC, receipts, защищённые проекции, репликация, сохранение и выбор узла. Локальные копии runtime удалены. Массивы объектов поддерживаются тем же библиотечным DSL.
- `useDraggableApi` обеспечивает mouse/touch/keyboard свободных заметок через один lifecycle. Границы, координаты, ревизии и изображение чужого движения остаются приложению. [R4 принят](../../doc/changes/react2-3.4.0.md); собственный обработчик клавиш удалён.
- Новых npm-зависимостей и собственного транспорта нет.
