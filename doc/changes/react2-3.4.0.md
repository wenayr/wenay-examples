# Принятие wenay-react2 3.4.0

10 сентября 2026. Оба приложения используют точные npm-версии common2 2.20.0 / react2 3.4.0; package-lock обновлены, локальных подмен нет. **R4 принят и закрыт.**

## Изменение примера

Свободные заметки встроенного и самостоятельного органайзера используют публичный `useDraggableApi`: `keyboard`, `enabled`, `handleProps`, `onDragCancel`. Удалены отдельный keyboard ref, обработчик клавиш, второе состояние движения и ручное согласование способов ввода. Mouse/touch/keyboard имеют одного владельца в библиотеке.

В приложении остаются координаты, ограничение канвы, учёт прокрутки, ревизия, поколение SC1, права, временная проекция и окончательная команда. Ограниченный delta возвращается через `setPosition`, чтобы стрелка сразу разворачивала движение у края. `trackState:false` сохраняет императивный предпросмотр без React-рендера на каждом шаге.

Ручка — настоящая кнопка. Приёмка выявила потерю фокуса при кратком native disabled во время сохранения. Потребитель использует `aria-disabled` и сохраняет фокус, а `enabled` библиотеки продолжает запрещать начало и отменять активный жест. Новый библиотечный механизм для этого не нужен.

## Проверки

- Typecheck обоих приложений; production-сборки пиццерии, органайзера и хостинга — прошли.
- `test:canvas`: реальные RPC, два редактора, роли, конфликт ревизий, границы, миграция, durable restart и ограничение частоты presence — прошёл.
- `test:collaboration`: SC1 права, отзыв/возврат доступа, переподключение, перезапуск authority, поколения, peer isolation — прошёл.
- Браузер, локальный сервер и две сессии owner/worker: Space, стрелки 10 и Shift 50; другой участник видит transient preview до сохранения, после Enter — сохранённое положение без ghost.
- Повторный жест сразу после commit без клика; Escape и Tab отменяют preview без изменения позиции. Фокус после commit/Escape остаётся на ручке.
- Левая граница: после избыточных шагов влево один шаг вправо даёт координату 10, без накопленного выхода за границу.
- Реальное перетаскивание мышью на 30/20 изменяет сохранённую позицию на 30/20; соседняя заметка сохраняет положение.
- Во время жеста owner другой сотрудник сохраняет новую ревизию. Жест отменяется, показано объяснение, несохранённое движение не применяется. Поле редактирования работает независимо от ручки.
- Соседний `useReorderBoard`: клавиатурный preview в другую колонку и Escape сохраняют исходный статус. Консоль итоговой вкладки без предупреждений и ошибок.

Браузерные проверки выполнены через UI и чтение DOM, без подмены состояния и обработчиков. Это не аппаратная приёмка touch и не новый Docker-прогон. Docker, VM и платные ИИ-вызовы для этого обновления не запускались. Сохранились прежние предупреждения сборки пиццерии о размере JS и будущем Vite config loader.

## Вывод для библиотек

Обновление полезно: общий механизм действительно заменил повторённый код приложения. Доказанных новых дефектов react2 не найдено. В [текущем пакете](../library-tasks/CURRENT-HANDOFF.md) остаются предложения common2 H1/H2. Исторические задания и отчёты сохраняются с отметками о закрытии.
