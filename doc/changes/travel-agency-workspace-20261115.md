# Кабинет агентства, витрина, отзывы и миниатюры цен

Мастер создаёт самостоятельное агентство внутри сервиса. Настройки бренда, контактов, направлений, источников и отображения сохраняются
в JSON R2 и применяются к интерфейсу и серверному поиску. На `/a/:slug` доступна клиентская витрина с формой настоящей заявки;
владелец получает обращение в кабинете, меняет статус и экспортирует обращения в CSV или JSON.

Профили и заявки изолированы по доверенной Sites identity. Публичная проекция содержит только деловые поля.
Конкурентные записи защищены R2 ETag и версиями. Короткий адрес резервируется условной записью и после создания постоянный.
Прерванное создание восстанавливается владельцем, незавершённый резерв не публикуется. Текущий owner-private доступ Site сохраняется.
Ценовой буфер остаётся ограниченным кэшем; SQL и база для промежуточных цен не добавляются.

В карточках отеля можно выбрать график либо миниматрицу. Они используют реальные полученные цены, длительности и даты.
Для выбранного видимого отеля подгружается небольшое окно матрицы; неизвестные, устаревшие и недоступные значения не заменяются выдуманными ценами.

Отзывы подключены через официальный коннектор Expedia Rapid с серверными ключами и точным сопоставлением ID объектов.
Без договора, ключей или сопоставления интерфейс честно показывает отсутствие источника. Реальных текстов API при этой проверке не получали:
учётные данные не предоставлены. Доступны проверенные внешние страницы отзывов отдельных отелей. Тестовые отзывы не попадают в каталог.
