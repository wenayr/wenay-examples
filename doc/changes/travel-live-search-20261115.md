# Живой поиск и всплывающая матрица — 15 ноября 2026

Поиск отеля на карте обращается к серверу с направлением, датами, длительностью, гостями и бюджетом. Результат позволяет сразу открыть всплывающую матрицу, выбрать реальный тариф и продолжить работу на карте. Сохраняются фотографии, отметки избранного, параметры поездки и просмотр длительностей.

Имена индексируются вместе с существующими диапазонными индексами. Выдаются ограниченные страницы подтверждённых цен и проверенных метаданных без тарифа. Отель не исчезает из каталога, когда в текущем ответе нет его цены. Цены отсутствующих предложений не вычисляются.

Ручное обновление обходит исходный кэш; обычные активные представления проверяются раз в две минуты. Старое наблюдение после неудачного обновления помечается явно и сохраняет исходное время. Пауза запросов и отмена читателя не превращаются в подтверждённое отсутствие тура.

Туровый серверный граф перенесён в Worker ESM без Node fs/SQLite/HTTP в runtime. Три проверенных JSON-манифеста включаются статически, Web Crypto сохраняет прежние fare IDs. Общий Request/Response router используется также прежним Node backend. Создание самостоятельного Site source и сборка воспроизводимы; инструкция и постоянный project ID находятся в `apps/travel/docs/LIVE-SITE.md`.

Проверка: 148 тестов Travel прошли; typecheck и профильные проверки поиска, пустого каталога, SHA-256, refresh/stale, очереди и диапазонных запросов прошли. Worker исполнил настоящие HTTP операции health/destinations/gallery и поиск Sand Beach с ценой 1384 EUR на 24 января 2027, исходным fare ID и временем наблюдения. Это отдельная проверка API, не синтетические цены для интерфейса. Финальная managed-проверка прошла: поиск → всплывающая матрица → выбор реального тарифа 938 EUR на 17 ноября → ручное обновление → Escape сохраняют выбранный тариф, камеру и запрос. Время источника действительно меняется при обновлении. После исправления объединения метаданных на карте остаётся одна карточка на hotel ID, с одним фото, названием, ценой и графиком. Нативные клавиши изменения даты обновляют маршрут и контекст. Публикация успешно завершена: https://wenay-travel-live.wenayr.chatgpt.site (owner-private).
