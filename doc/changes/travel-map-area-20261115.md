# Поиск по области карты и компактные карточки

Карта определяет поиск гостиниц и тарифов. Перемещение и масштаб выбирают пересекающиеся подключённые регионы; ручной выбор направления перемещает карту и не остаётся скрытым фильтром. Каждая гостиница сохраняет регион источника для своего календаря и матрицы.

Карточка сворачивается при уменьшении масштаба и не остаётся за пределами экрана из-за избранного. Её можно отодвинуть за ручку; линия связывает карточку с настоящей точкой отеля. Фото, название, мини-график и цена сохранены. Действия, источники фото, матрица и обновление показаны иконками с подсказками; настройка включает подписи. Отдельная ссылка на выбранный отель сохраняет только проверенные метаданные и помогает вернуться после перемещения карты.

Статические официальные манифесты содержат 145 уникальных геолокированных гостиниц с фотографиями: 62 Хургады, 56 Шарма и 27 Родоса. Добавлены 88 галерей и 440 точных ссылок, для каждого нового главного снимка проверен HTTP GET. Пять объектов без опубликованных координат не превращаются в маркеры.

Новый регион Анталии разрешается лениво из официального reference: город вылета 3746, страна 1104, `tours[].tourId=1285`. Справочник страны содержит 472 гостиницы; после точного отбора региона остаются 27 действительных ID. Все сохраняются в поиске. Порции по восемь обогащают очередные ID координатами и фотографиями официальной страницы, затем индекс обновляется независимо от изменения цены. Размер порции не ограничивает общий ассортимент.

Реальный Шарм viewport HTTP-запрос с прежним `destination=hurghada` выбрал только регион 5735 и получил 53 опубликованных ценовых минимума и три известных гостиницы без тарифа. Проверка метаданных Анталии получила восемь точных позиций и фото за 16,9 секунды, остальные 19 ID сохранила без вымышленной позиции. В этой проверке ценовой 429 был воспроизведён из ранее записанного фактического ответа, а reference, каталог и карточки запрашивались живьём. Новых запросов тарифов после ограничения источника не делали.

Фактический HTTP 429 учитывает `Retry-After` и включает общую паузу ценового источника. Старые цены сохраняют исходное время и состояние `stale`. Промежуточные результаты используют ограниченные очереди, TTL, объединение одинаковых запросов и вытеснение старых записей в памяти. Новая БД не добавлялась; постоянные подтверждённые манифесты остаются JSON-файлами.

Проверки — 165 тестов Travel прошли, включая происхождение региона, bbox за прежней городской границей, частичные данные, разные порции метаданных при той же цене, cooldown, отмену соседнего читателя и координаты/фото. Managed browser-проверка root подтвердила drag/линию, масштаб/избранное, подписи, Шарм, pan→reload→locate с точной позицией и Анталию с сохранением региона popup после перезагрузки. После естественного прохождения паузы фактический preview получил опубликованную цену ADALYA 2045 € за всю группу и соседние предложения; это наблюдение источника, не постоянная цена. Стиль изменённых TS/TSX/MJS и проверка пробелов прошли.
