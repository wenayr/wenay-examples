# Внутренний рабочий контекст

Здесь лежит то, что нужно для продолжения работы, но не является документацией продукта: контекст передачи между сессиями, контрольные точки, журналы выполнения, отчёты о ручной приёмке и инвентаризация библиотечных возможностей.

- [NEXT-CHAT](NEXT-CHAT.md) — состояние и активное поручение на момент последней паузы.
- [Контрольная точка 10 сентября 2026](SAAS-CHECKPOINT-2026-09-10.md) — что сделано, что не объявлено готовым.
- [progress/](progress) — журналы отдельных работ. Живут, пока работа не закончена.
- [acceptance/](acceptance) — детальные отчёты ручной и браузерной приёмки, на которые ссылаются README приложений.
- [saas-library-inventory](saas-library-inventory.md) — карта публичных возможностей common2/react2 и их потребителей.
- [archive/](archive) — планы, выполненные или заменённые более новыми.

Публичные документы — уровнем выше: [правила кода](../CODE-RULES.md), [план развития](../ROADMAP.md), [состояние каталога](../STATUS.md), стратегии и `changes/`.
