# Приёмка интерфейса Accord (approvals)

Дата: 11 сентября 2026. Задача A03 [плана 2](../../CONSOLIDATION-PLAN.md). Проверка выполнена в браузере на запущенном `npm start`, порт 3818, чистый каталог данных.

Две вкладки одновременно: сотрудник `requester` и проверяющий `reviewer`. Третья роль — владелец `owner` — проверена в той же первой вкладке после смены сессии.

## Пройденные сценарии

| Сценарий | Что наблюдалось |
| --- | --- |
| Экран входа | Обе колонки, предустановки ролей переключают аккаунт и пароль, вход по кнопке |
| Создание заявки | Форма показывает название и три вопроса анкеты; сохранение создаёт черновик, карточка появляется в списке |
| Отправка версии | Статус `На рассмотрении`, редакция 2, появляется блок отправленной версии и история с записью «Отправлено · версия 1» |
| Отправленная версия только для чтения | Поля версии заполнены сохранёнными значениями и заблокированы: «Хотим научиться…», 48000, `false` |
| Живое обновление | Вкладка проверяющего увидела заявку без перезагрузки; после решения вкладка автора обновилась сама |
| Решение с подтверждением | Окно `Overlay` называет номер версии и показывает текст комментария до подтверждения |
| Возврат на уточнение | Статус `Нужны уточнения`, счётчик «1 нужно уточнить», история добавила запись проверяющего с комментарием |
| Повторная правка и версия 2 | У автора снова открылась форма; после отправки в выборе две версии, история из трёх записей |
| Согласование | Статус `Согласовано`, счётчик «1 согласовано», история из четырёх записей, окно закрылось |
| Условный вопрос | Ответ «Да» на «Нужно срочно?» добавляет четвёртый вопрос «Почему нельзя подождать?»; «Нет» убирает его |
| Панель команды владельца | Четыре участника с ролями, список вариантов включает отзыв доступа |
| Защита последнего владельца | Попытка снять роль у единственного владельца даёт сообщение «Нужен хотя бы один владелец», значение в списке не изменилось |
| Узкий экран 375px | `scrollWidth` равен `clientWidth`: горизонтального переполнения нет, шапка, метрики, фильтр и карточки читаются |

## Что не проверялось этим проходом

- Реальный отказ узла и рестарт авторитета в браузере: это покрывает `backend/check.ts` отдельными процессами.
- Скринридер и полная клавиатурная навигация: проверены только видимые `aria-label` у полей анкеты, ролей и кнопки закрытия окна.
- Docker-развёртывание проверено отдельно: `npm run test:approvals` из `apps/hosting`; сводка — [отчёт K08](../../reports/K08-approvals.md).
