# Folio: приёмка интерфейса

10 сентября 2026. Published npm `wenay-common2 2.21.1`, `wenay-react2 3.5.1`. `npm run typecheck` и `npm run build` прошли; проверенный frontend `index-DWEFEkkq.js`. Живой standalone сервер `http://127.0.0.1:3817/`, браузер Chrome.

## Пройденные пользовательские цепочки

- Автор поменял текст и перенёс блок клавиатурой через публичный `useReorder` (пробел, стрелка, Enter), затем вернул порядок и сохранил. Предпросмотр показывает обычный текст, а не HTML.
- Демонстрационный помощник подготовил отдельное предложение: лишние пробелы и первая буква. До явного принятия черновик не изменился; принятие выполнило обычное сохранение исходной revision. Интерфейс прямо сообщает, что это тестовый обработчик без языковой модели и платных запросов.
- Кнопка примера создала настоящий PNG, загрузила его через файловый ресурс; изменено описание, изображение добавлено в блок с альтернативным текстом. Оно появилось в предпросмотре, снимке и публичной статье. Системный выбор файла отдельно не проверен: расширение Chrome запрещает загрузку локальных файлов без дополнительной пользовательской настройки.
- Автор отправил снимок v1. Редактор добавил комментарий к версии и согласовал её. У редактора не было действия публикации; у издателя не было редактирования черновика или согласования.
- Издатель назначил публикацию на будущую дату, увидел зону Europe/Moscow, отменил расписание, затем опубликовал v1 через отдельное подтверждение. Исполнение расписания по времени проверяется backend network-тестом, здесь проверены создание и отмена.
- Анонимная ссылка `/#read=northstar/welcome` показала только опубликованный текст и настоящее изображение. Аккаунт reader видит только журнал, без черновиков, медиатеки и редакторских комментариев.
- Владелец создал и согласовал v2. Сохранение черновика не изменило уже открытую анонимную статью; публикация v2 обновила её без reload. Откат на v1 вернул прежний заголовок. Снятие публикации удалило текст и изображение из открытой страницы и показало сообщение о недоступности. В конце снова опубликована v2.
- Вторая вкладка под автором была открыта в редакторе. Смена его роли на reader немедленно убрала редактор и приватные изображения, оставив журнал. После восстановления роли отдельный вход outsider показал только пустую редакцию Harbor, без Northstar.
- В основных служебных вкладках не было предупреждений или ошибок консоли. HTTP 404 при снятии статьи ожидаем и обработан.

## Использование библиотек и границы проверки

Сессия, доступные фасады, проекции и смена прав используют `useServiceSession`, `ServiceView`, `useClientStore`, `useOwnedClient`; прогресс AI — публичный `useStoreReplayMirror`, команды — типизированные common2 facade. Частный результат AI читается отдельно с актуальной проверкой доступа и источника. Перестановка — `useReorder`, подтверждения — публичный `Overlay` из react2. Смена роли/организации размонтирует приватное состояние. Нового транспорта или reconnect-цикла нет.

Публичный реактивный view только сигнализирует изменение публикации; содержимое перечитывается через authority HTTP с `no-store`. Нельзя удалить уже скачанные читателем байты или сторонние копии. PNG пример проверяет реальный upload, но не заменяет проверку всех вариантов пользовательских файлов.

Desktop screenshot просмотрен непосредственно в браузере. Mobile CSS существует, но в этой приёмке Chrome viewport override не применился к нужной вкладке (измеренная ширина 1755 px); мобильный результат здесь не заявляется и передан координатору для отдельного in-app browser прогона.
