# Orbit CRM: браузерная приёмка

10 сентября 2026, локальный preview `http://127.0.0.1:3813`, опубликованные common2 2.21.1 / react2 3.5.1. Проверки проводились в Chrome через интерфейс приложения, с отдельными тестовыми аккаунтами. Платных запросов не было.

## Пройдено

- Вход владельца; воронка с реальными сведениями CRM. Публичный `useReorderBoard`: Space → Right → Enter перевёл сделку из нового контакта в обсуждение.
- Карточка: черновик предложения на 2400 условных единиц, сохранение, явная публикация версии 1, переход сделки в этап предложения.
- Отдельная сессия клиента: видит только связанную сделку, публичное сообщение и опубликованное предложение. Внутренняя заметка, черновик, помощник, импорт и задачи скрыты. Клиент принял версию 1 с комментарием; первая сессия получила результат без reload.
- На доске сотрудника появилась задача выполнения предложения, назначенная менеджеру, со ссылкой на сделку и двумя пунктами проверки.
- Помощник: запуск через AI runtime, чтение защищённого результата, список источников. После решения клиента старый отображавшийся результат исчез; повторное чтение отказало с требованием новой сводки. Исполнитель прямо обозначен как тестовая сборка фактов, а не языковая модель.
- CSV: встроенный пример загружен через SC1 imports; проверено сопоставление имени/email/телефона. Выполнение вернуло 2 добавленных контакта, 1 дубликат и 1 ошибку email. Контакты появились в общем справочнике.
- Ручной контакт и новая сделка на 850 условных единиц. Таблица на `AgGridTable`/`useAgGrid` react2; выбор сделки и групповое назначение менеджеру обновили строку.
- Typecheck и production build пройдены. Ошибок и предупреждений в консоли проверенной CRM-вкладки нет.

## Границы доказательства

Отмена/возобновление CSV, отзыв роли и конкуренция проверяются отдельными backend/network сценариями; быстрый CSV из четырёх строк не использовался как доказательство UI отмены во время исполнения. Ролевые сценарии manager/lead и другая организация имеют отдельные серверные проверки; браузерная цепочка выше конкретно owner/customer.

Мобильное оформление реализовано; отдельный браузерный замер CRM пока не завершён: override размера Chrome применился к другой вкладке. Снимок desktop в истории UI-инструмента не объявляется мобильной приёмкой. Инструмент выдаёт снимок как изображение/bytes, без документированного сохранения в локальный PNG.

Дополнительная root приёмка: viewport390×844, clientWidth375=scrollWidth375 на обзоре и карточке сделки. Модальные окна переведены на публичный Overlay из wenay-react2/ui; Escape закрывает, Shift+Tab/Tab удерживают фокус внутри, закрытие возвращает его исходной кнопке. Typecheck/build PASS.
