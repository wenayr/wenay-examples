# D06 — повторная браузерная приёмка рабочего места проверки

Дата: 11 сентября 2026. Задача E01 [плана 3](../../PLAN3-TASKS.md). Строка [D06](../../SAAS-EXAMPLES-BACKLOG.md) требовала переприёмки интерфейса после добавления сравнения версий.

## Как проверяли

Студия документов запущена обычным способом (`npm start`, порт 3811, **пустой** каталог данных), вход проверяющим через кнопку демо-аккаунта.

1. «Загрузить пример» — появился документ «Смета — сентябрь.csv», состояние «Загружен», 0 строк.
2. «Обработать документ» обработчиком Node — состояние «На проверке», версия 3, извлечены 4 строки и 4 колонки. Оригинал показан рядом с таблицей.
3. «Подтвердить документ» — состояние «Подтверждён», версия 4, появились выгрузки CSV и JSON.
4. «Вернуть на проверку», затем «Исправить строку 3»: цена 8000 → 9500, комментарий «Сверено с оригиналом при приёмке D06», «Сохранить строку».
5. Повторное «Подтвердить документ» — версия 7.
6. Вкладка «Сравнить версии», в списке выбрана «Версия 4 · исходник 1».

## Результат

Сравнение показало подпись «Слева — утверждённая v4, справа — текущая v7» и таблицу всех 16 ячеек. Изменённой отмечена ровно одна строка:

| Строка / поле | Утверждено | Сейчас | |
| --- | --- | --- | --- |
| 3 · Цена | 8000 | 9500 | Изменено |

Остальные пятнадцать ячеек совпадают. То есть утверждённая версия 4 сохранила прежнее значение после исправления и повторного утверждения — неизменность утверждённой копии видна прямо в интерфейсе.

Выгрузки CSV и JSON появляются только в состоянии «Подтверждён» и исчезают после возврата на проверку.

## Границы этой проверки

- Содержимое выгруженных файлов в браузере не проверялось: загрузка файлов в этой среде запрещена. Точные байты CSV и JSON проверяет `backend/product-check.ts` в составе `npm test`.
- По умолчанию вкладка сравнения открывается на текущей версии (v7 против v7) — нужную утверждённую версию выбирают в списке. Это не дефект, но и не самый удобный выбор по умолчанию: замечание записано в отчёт плана 3.
- Проверялся один проверяющий в одной организации; разделение ролей и изоляция организаций проверяются доменными тестами.
