# Petal — приёмка и история

Перенесено 11 сентября 2026 из `apps/forms/README.md` (задача R04 [плана 3](../../PLAN3-TASKS.md)). Это результат приёмки на указанные даты, а не действующая инструкция. Текущее состояние проверок — [STATUS](../../STATUS.md).

## Чистая копия и размещение

Из корня репозитория: `node scripts/create-saas-example.mjs forms <новый-пустой-каталог> --name my-forms`. Копируются только разрешённые исходники, точные npm-зависимости и правила; пользовательские ответы, частные результаты, `.env`, зависимости и прежняя сборка исключены. В отдельной копии прошли `npm ci`, typecheck, build и весь `npm test` без соседних приложений.

Настоящая проверка хостинга: `npm run test:forms` из `apps/hosting`. Пройдены запуск `first`, обновление `second` и откат: постоянный gateway и том сохраняют публикацию, три ответа, ручную группировку и JSON-экспорт. Отзыв аналитика и публичной ссылки сохраняется после отката; старые bearer-токены явно отклоняются стандартным API библиотеки.

## Интерфейс Petal

Готов самостоятельный frontend: редактор вопросов с публичным `useReorder`, работающий условный предпросмотр, публикация по подтверждению, отдельная сессия участника, iframe, итоги и страницы ответов, исправление/удаление, выгрузка и ручная корректировка тестовых тем. Реальная ссылка frontend имеет вид `/#respond=...`; пример `/respond#token=...` выше описывает альтернативное размещение, а не маршрут этого приложения.

Пройдены desktop-сценарии редактора, клавиатуры/мыши, скрытых ответов, публикаций, отправки, исправления/удаления, устаревшей выгрузки, группировки, смены роли и организации, реального iframe и отзыва открытой публичной сессии. Детальное доказательство и границы проверки: [FORMS-UI-ACCEPTANCE](FORMS-UI-ACCEPTANCE.md). Мобильную проверку отдельным проходом выполняет root; она не выводится из desktop-скриншота.
