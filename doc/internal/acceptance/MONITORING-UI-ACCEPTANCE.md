# Signal — приёмка интерфейса

10 сентября 2026. common2 2.21.1, react2 3.5.1. Проверка через настоящий браузер и опубликованные клиентские фасады.

- Владелец создаёт публичную проверку локальной поддержки. Реальные HTTP 200 появляются через встроенный обработчик; журнал обновляется без перезагрузки. Сводка по фактам создаётся и читается; новое измерение убирает прежний текст, повторное чтение отклоняется сервером как устаревшее.
- Отдельный `backend/ui-fixture.ts` создаёт явно обозначенный демонстрационный отчёт 503 через обычные команды probe. Дежурный видит инцидент, добавляет внутреннюю заметку и переводит его в работу.
- Появляется одна задача с назначенной дежурной и двумя пунктами проверки. Первый пункт отмечен, карточка переведена в работу. После тестового восстановления инцидент закрывается, но задача остаётся незавершённой. Дежурный отмечает второй пункт и завершает её; загруженность становится нулевой.
- Личное уведомление отмечается прочитанным; тихий режим сохраняется. Публичная страница показывает восстановление и время, не содержит внутренней заметки или сведений об обработчике.
- Наблюдатель видит открытый монитор и сокращённый журнал, без сводки, настроек, задач и команды. Outsider видит Harbor Labs без Northstar-проверок.
- Мобильный публичный статус и кабинет наблюдателя: viewport390×844, clientWidth390=scrollWidth390. Визуально проверены заголовки, карточки, история и навигация; горизонтального переполнения нет. Console warn/error пусты на новой вкладке.
- Overlay устанавливает фокус на закрытие; Escape закрывает карточку. При недействительной сохранённой сессии доступны повтор подключения, выход к публичному статусу и новый вход. Этот путь действительно пройден после смены тестового архива.

Настоящий HTTP-сбой, отключение обработчика, подхват вторым, две обслуживающие реплики и восстановление после рестарта отдельно проверены в `backend/check.ts`. UI-fixture не выдаётся за реальное измерение. Автоматических команд хостингу нет: только переход к его обычному кабинету.

В процессе проверки исправлена подпись источника задачи («Инцидент» вместо скопированного «Сделка»). Typecheck/build и окончательная упаковка после этой текстовой правки выполняются отдельно.
