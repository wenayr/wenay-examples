# C5 — общий ресурс дочернего процесса (дополнительный кандидат)

common2 2.17.0, пример 0.8.0. Полезное повторное использование Node IO; существующее приложение работает без нового API.

**Факт.** `backend/process-resource.ts:6-57` реализует spawn, IPC readiness, ограниченное ожидание старта, хвост stdout/stderr, early exit и повторяемый bounded stop. Его используют сеть пиццерий и тест самостоятельного органайзера. В published `examples/hosting/process-resource.ts` есть ещё одна обвязка процесса с подобным lifecycle. В проверенном `resource` entrypoint экспортируются file-job host/client, не этот процессный ресурс.

**Работа.** Выделить небольшой Node-only ресурс с явными argv/cwd/env, функцией распознавания readiness, ready/done, событиями отказа и идемпотентным close. Пределы времени, протокол штатного shutdown и объём хвоста вывода конфигурируемые. Опираться на child_process; не создавать shell-строку, локальный кластерный scheduler или новый RPC.

**Приёмка.** Never-ready процесс закрывается по deadline; ранний exit отклоняет ready; одновременно вызванные close приводят к одному завершению; превышение бюджета graceful shutdown вызывает принудительное закрытие. После отмены запуска не остаётся child. Проверить Windows hidden-process поведение и Linux. Адаптировать оба имеющихся examples через этот ресурс; branch topology/секреты/решение сколько узлов нужно остаются продукту.
