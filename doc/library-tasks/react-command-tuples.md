# R2 — коррелированный вызов команды при передаче между компонентами

react2 3.2.0, common2 2.17.0, пример 0.8.0. Небольшая задача удобства типизации; существующий прямой generic run не объявляется неисправным.

**Факт.** `shared/react/command-action.ts:3-10` заново определяет tPayload/tCommandCall и приводит controller.run к объединению кортежей. `command-action.types.ts` проверяет связь имени и payload отрицательными примерами. Публичный `ServiceCommandsController` имеет generic run, но используемый им `CommandArgs` приватный; готового публичного типа коррелированной команды нет.

**Работа.** Экспортировать тип вроде `ServiceCommandCall<C>` и предоставить типобезопасную передачу такого кортежа обратно в controller — overload или отдельный runTuple. Не менять удачный прямой `run('name', input)` и вывод результата. Сначала показать compile-only пример прокидывания вызова через 2 компонента без `as`.

**Приёмка.** Неизвестное имя и payload другой команды отвергаются. Поддерживаются команды без аргументов после requestId и с несколькими аргументами; при известном имени сохраняется точный тип результата. В примере удаляются повтор conditional types и cast execute. Один requestId на запуск, pending/error, original rejection и запрет автоматических retries сохраняются. Не создавать форму или runtime-схему ради передачи типов.
