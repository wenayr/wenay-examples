# R3 — автопрокрутка переноса (необязательное расширение)

react2 3.2.0, органайзер 0.8.0. В `useReorderBoard.d.ts` отсутствие autoscroll явно объявлено non-goal. Это запрос расширения для конкретного сценария, не нарушение текущего обещания библиотеки.

**Факт.** Доска горизонтально прокручивается на узком экране; длинная колонка может выходить за viewport. Сейчас нужно заранее прокрутить контейнер или поменять статус через select. См. `organizer/style.css`, `organizer/README.md`, public `useReorderBoard`.

**Работа.** Рассмотреть маленький opt-in edge-scroll controller для useReorder/useReorderBoard. Если он требует превращения простого hook в полный DnD engine, вместо этого предоставить пример совместимого подключения готового DnD-адаптера. Не добавлять вложенные доски, collision packing и отдельную предметную модель.

**Приёмка расширения.** У края прокручивается ближайший разрешённый scroll container с ограниченной скоростью; измерения, target и overlay корректны после прокрутки. Прокрутка прекращается при drop/cancel/unmount, вне края не запускается. Проверить горизонтальный мобильный board, длинную колонку, вложенный scroll-container и настройки reduced motion. Один commit на завершение сохраняется. Согласовать activator/cancel с R1 до правок общего hook.
