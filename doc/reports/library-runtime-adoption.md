# Переход на публичный service runtime

9 сентября 2026: переход завершён в приложении **0.9.0** на точных npm-версиях **wenay-common2 2.18.1** и **wenay-react2 3.3.0**. React2 использует тот же экземпляр common2. Зависимости и integrity закреплены в lockfile; локальных подмен нет.

## Что применено

| Задание | Изменение потребителя |
| --- | --- |
| C1 | Контроллер сети подтверждает исключение всех выбранных узлов через `leader.control.drain` до остановки процессов. Приватный маршрут защищён секретом node corridor; пользовательский токен владельца его не открывает. При аварии сохраняется обычный failover. |
| C2 | Оба интерфейса используют `wenay-common2/service/client`, опубликованный безопасный descriptor и полный `identity.me()`. Собственный клиент удалён. |
| C3 | Definitions/DSL и серверная композиция импортируются из `service`/`service/server`. Удалены 8 скопированных файлов: client, leader, node, access, rest, input-schema, config, panel — 2310 строк. Массивы объектов для рецептур и чек-листов поддержаны опубликованным patch 2.18.1. |
| C4 | Entrypoints используют `service/host`, общий HTTP/WS CORS, асинхронный cleanup и IPC shutdown. Прямой `process.exit` в serving-node заменён освобождением хоста. |
| C5 | Управление дочерними процессами сети, органайзера и тестового стенда передано `createProcessResource`; приложение задаёт entrypoint, env, readiness и IPC-протокол. Бюджет принудительной остановки 5 секунд покрывает 2 секунды graceful drain и cleanup. |
| C6 | Фотографии хранятся через `createLocalBlobStorage` и `createBlobHttpRouter`. Форматы, ACL, лимит 2 МБ, публичный кеш и идентификатор `sha256.extension` остались продуктовой политикой. Старые файлы читаются без миграции. |
| R1 | Ручка стала кнопкой с `handleProps`, добавлены инструкции клавиатуры и live-объявление позиции. |
| R2 | Используются `ServiceCommandCall` и `runTuple`; локальные conditional types и приведение generic run удалены. |
| R3 | Включена ограниченная автопрокрутка только доски и её колонок. |

## Подтверждённые проверки

- `npm run typecheck`, полный `npm test`, `npm run build`, `npm run build:organizer` проходят на 2.18.1/3.3.0.
- Inventory: рецептуры, роли, FEFO, резерв, порча, просрочка, отмена, receipt и миграция — PASS. Organizer: сотрудники, сроки, непустой чек-лист, завершение/возобновление, права, конфликты ревизий и durable restart — PASS.
- `backend/host-check.ts`: ownership без process signals, согласованные HTTP/WS origins, async cleanup ровно один раз, закрытый порт, прежние URL/байты фотографий, дедупликация, запрет чужой загрузки, неверный формат и oversized body.
- `backend/check.ts`: настоящий стенд, REST/RPC, роли, обычный цикл заказа — ALL GREEN.
- `backend/network-check.ts`: независимые заведения, токены и файлы, отзыв/возврат прав, реальная авария узла, масштабирование, restart, архив и receipts — PASS. На 2.18.1 замер scale-to-zero + перехода к leader: **2071 мс** вместо прежнего перебора адресов около 20 секунд.
- Браузер: создание ручной задачи с непустым чек-листом, отказ завершения до проверки и успешное завершение после отметки; новое блюдо с двумя ингредиентами сохранено и видно в публичном меню с описанием и составом. Консоли без ошибок. Ранее в этом переходе проверены перенос клавиатурой, отмена Escape, перенос мышью и восстановление фокуса после replay. Автопрокрутка подключена, но непрерывное удержание у края и реальное touch-устройство в этом проходе не подтверждены.

## Исправление, полученное при внедрении

В 2.18.0 `schemaCommand` допускал только массивы скаляров. При внедрении обнаружились TS2322, ошибочное требование ISO day для объекта и пустая OpenAPI-схема элемента. [Задание на patch-релиз](../library-tasks/service-schema-object-arrays.md) закрыто версией 2.18.1 без изменения формы команд приложения, ослабления типов или локальной подмены npm-пакета.

Общие механизмы теперь действительно живут в npm-пакетах. Предметные правила, топология заведений и небольшие адаптеры IO-протоколов остаются в приложении. Выгода подтверждается удалённым сопровождаемым кодом и реальными проверками. Процент экономии времени не измерялся.
